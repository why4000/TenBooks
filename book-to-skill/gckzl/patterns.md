# Patterns

## Pattern 1: 反馈回路设计 (Feedback Loop Design)
**When to use**: 开环控制精度不够、对象参数不确定，或扰动频繁。

**How**:
1. 明确被控输出与期望输入。
2. 选传感器测量输出，构造偏差 `e=x-y`。
3. 设计前向控制器 `F1(s)`，使环路增益足够大以压低稳态误差。
4. 用乃氏图/路斯判据检查闭环极点是否全在左半平面。
5. 检查快速性：闭环零点是否足够远离虚轴。
6. 在稳定性、快速性、精度之间折衷，留出相位裕度。

## Pattern 2: 传递函数建模 (Transfer-Function Modeling)
**When to use**: 需要把物理系统抽象成可计算、可组合的输入—输出模型。

**How**:
1. 确认工作点，做线性化与常系数近似。
2. 列微分方程，取零初始条件做拉氏变换。
3. 求 `F(s)=Y(s)/X(s)`，整理成多项式之比。
4. 标出极点、零点、放大系数。
5. 令 `s=iω` 画伯德图/乃氏图，核对频域行为。
6. 用串联相乘、并联相加、反馈闭环公式组合部件。

## Pattern 3: 稳定性判定 (Stability Analysis)
**When to use**: 闭环系统设计完成，或参数变化后需要重新确认稳定。

**How**:
1. 写出闭环特征方程（分母）。
2. 优先用路斯—胡尔维茨判据做代数快筛。
3. 需要物理直觉时画乃氏图，数绕 `-1` 点的圈数。
4. 改变增益，观察稳定边界与临界频率。
5. 若含时滞，改用萨奇图，检查 `g2` 是否在 `g1` 外侧。
6. 给出稳定裕度，而不是只给"稳定/不稳定"二值结论。

## Pattern 4: 时滞系统稳定化 (Time-Lag Stabilization)
**When to use**: 传感器、执行器、燃烧或传输过程存在不可忽略的纯滞后。

**How**:
1. 标定时滞 `τ` 及其变化范围。
2. 写出含 `e^{-sτ}` 的超越特征方程。
3. 用萨奇图分离时滞项，判断临界时滞与临界频率。
4. 若 `τ` 不确定，降低环路增益或改用绝对稳定设计。
5. 必要时加入补偿环节，但不要把补偿建立在"τ 精确已知"的假设上。

## Pattern 5: 噪声过滤设计 (Noise Filtering Design)
**When to use**: 信号弱于干扰，或测量通道噪声显著。

**How**:
1. 估计信号与噪声的相关函数/功率谱。
2. 设定希望输出 `z(t)` 与允许的延迟。
3. 以平均平方误差 `E[e²]` 为目标。
4. 在可实现性约束下（因果、极点全在左半平面）求最优 `F(s)`。
5. 用维纳—辛钦关系与谱分解求解。
6. 验证过滤后噪声功率与信号失真。

## Pattern 6: 自行镇定与自适应设计 (Self-Stabilizing & Adaptive Design)
**When to use**: 系统复杂、故障不可枚举，或环境持续变化。

**How**:
1. 定义可接受运行域及其边界。
2. 选定可切换的参数集合，确认其中至少存在一个稳定配置。
3. 设越界触发规则：轨迹碰边界即切换参数。
4. 允许随机或按规则搜索，保留能回到稳定点的配置。
5. 对连续干扰重复适应，记录"老练"后的参数。
6. 用仿真验证：所有初始点最终进入稳定域。

## Pattern 7: 解耦设计流程 (Decoupling Design)
**When to use**: 多变量系统，各被控制量之间存在明显交叉影响。

**How**:
1. 列出全部被控制量与可操纵输入，确认输入个数不少于需要控制的量。
2. 由理论分析或频率特性实验求出对象传递函数矩阵 `E`。
3. 按第四章方法逐个设计对角控制传递函数 `C_gg`，使每个单回路满足稳定、快速、精度。
4. 用发动机矩阵的余因式求出非对角元素与对角元素之比。
5. 令不需要的交叉项为零，其余按比值填入，得到完整控制矩阵。
6. 以反应方程核对：每个被控制量是否只受自己的给定值与扰动支配。
7. 在实际工况变化范围内复核（如飞行高度改变会使所需比值漂移）。

## Pattern 8: 采样系统设计流程 (Sampled-Data Design)
**When to use**: 反馈回路含周期性闭合的采样开关，或信号只在离散时刻更新。

**How**:
1. 确定采样周期 `t0` 与开关闭合时间比，确认可用冲量近似。
2. 由连续反馈传递函数 `F2(s)` 求周期传递函数 `F2*(s)`（留数法或部分分式加双曲余切）。
3. 写出 `Y*=F1X*/(1+F1F2*)`，与连续系统方程对齐。
4. 检查 `1+F1F2*(s)` 在右半平面无零点；因周期性只需考察宽 `2π/t0` 的竖条。
5. 画退化后的乃氏围线，确认不绕 `-1` 点。
6. 用 `1/(1+F1F2*(0))` 核算阶跃稳态误差，必要时提高 `F1`。
7. 若 `F2(s)` 在原点有极点，改用开放围线判断。

## Pattern 9: 继电器系统描述函数分析 (Describing-Function Analysis)
**When to use**: 回路含继电器、齿轮间隙、饱和等"频率迟钝"非线性。

**How**:
1. 实测或推导非线性环节对基波的等效增益与相移，确认它只随输入振幅变化。
2. 画出 `-Fr(ia)` 轨迹：起点为开断点，终点为原点。
3. 画出线性部分 `1/F1(iω)` 轨迹。
4. 若 `1/F1` 包围整条 `-Fr` 曲线则稳定；完全不包围则不稳定。
5. 两线相交则为等幅自激，判断交点是收敛点还是发散点。
6. 若需最优性能，改用相平面求最优开关曲线，并设开断计算机抑制颤震。

## Pattern 10: 极值搜索控制设计 (Extremum-Seeking Design)
**When to use**: 对象特性无法事先确知，或会因磨损、环境变化而缓慢漂移。

**How**:
1. 确认输出对输入在最优点附近近似为抛物线，确定曲率系数。
2. 估计噪声谱，找出去噪安静带，把试探频率放在该带内。
3. 选定搜索周期 T 与搜索范围 D，按 `D*=kD²/3` 评估搜索损失。
4. 实现反转逻辑：微分阈值法、正弦相乘滤波法，或电容峰值记忆法。
5. 若噪声安静带很窄，优先选峰值记忆方案，避免微分放大高频噪声。
6. 令临界电压差大于噪声振幅，防止误反转；必要时加过滤器。
7. 核算输入/输出线性部分的时滞，确认搜索周期远大于其时间常数。

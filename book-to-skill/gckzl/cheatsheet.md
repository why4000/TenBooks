# Cheatsheet: 工程控制论

## 决策规则
| 当你... | 做什么 |
|---|---|
| 对象参数不确定、扰动频繁 | 改用闭环反馈，用偏差驱动 |
| 稳态误差大 | 提高环路增益，但先检查相位裕度 |
| 系统反应慢 | 把闭环极点往左移，或提高增益 |
| 系统持续振荡/发散 | 查闭环极点是否在右半平面，画乃氏图 |
| 只拿到微分方程 | 做拉氏变换，求传递函数，看极点 |
| 回路里有纯滞后 | 用萨奇图，判断临界时滞，争取绝对稳定 |
| 输入只能用统计量描述 | 用相关函数/功率谱，按 `|F(iω)|²` 算输出 |
| 弱非线性、阻尼良好 | 可做线性近似；接近共振则不能 |
| 继电器/饱和/间隙导致自振 | 用描述函数找极限环，或反设计非线性 |
| 故障不可枚举 | 设可接受边界，越界切换参数（自行镇定） |
| 元件会"输出错误"而非"无输出" | 用多重化+随机重排+复原机构，而非简单并联 |
| 信号被噪声淹没 | 按平均平方误差最小设计维纳过滤器 |
| 多变量互相耦合、调一路扰动另一路 | 设计控制矩阵使其对角线化，先满足不互相影响条件 |
| 回路含采样器/开关周期性闭合 | 用 Stibitz-Shannon 理论求 `F2*`，判 `1+F1F2*` 不绕 `-1` 点 |
| 含继电器/间隙/饱和等频率迟钝非线性 | 用柯氏法：`1/F1` 须包围整条 `-Fr(ia)` 轨迹 |
| 要求扰动后最快回到原点 | 相平面求最优开关曲线，并设开断计算机防颤震 |
| 对象系数随时间变化（火箭燃烧等） | 别谈一般稳定性，改用摄动方程 + 伴随函数设计 |
| 性能可用积分写清（误差平方/超温/时间） | 用拉格朗日乘子 + 欧拉—拉格朗日方程反解控制律 |
| 对象特性未知或缓慢漂移 | 极值搜索：小幅试探 + 观察输出方向 + 控制在安静频带 |
| 信号弱于噪声且需最优过滤 | 谱分解取左半平面部分，注意极点位置保证可实现 |

## 关键概念速查
- 传递函数 = 零初始条件下输出/输入的拉氏变换比
- 稳定 ⇔ 闭环极点全在 s 左半平面
- 闭环传递函数 = `F1/(1+F1F2)`
- 反馈三准则 = 稳定、快速、精确（增益 `K≫1`）
- 时滞 = 相位滞后、稳态增益不变，传递函数含 `e^{-sτ}`
- 白噪声 = 功率谱常数、相关函数为冲量
- 维纳—辛钦 = 相关函数 ↔ 功率谱
- 极限环 = 相平面孤立闭轨 = 自激振荡
- 自行镇定 = 越界换参数，保留稳定形式
- 复合方法 = 多路线束 + 随机重排 + 复原机构
- 复原阈值 = `a'=2a(1-a)`，`a<0.618` 时误差收敛

## Tells & Smells
- **Smell**: "模型足够准，不需要反馈" → 开环对参数漂移和扰动毫无免疫力。
- **Smell**: "增益再调大一点就好了" → 精度上去，稳定裕度下来。
- **Smell**: "延迟可以忽略" → 时滞常在调试后期才暴露为振荡。
- **Smell**: "多并联几套就可靠了" → 只防无输出，不防错误输出。
- **Smell**: "局部稳定，所以全局稳定" → 非线性系统可能同时存在稳定与不稳定平衡点。
- **Tell**: 乃氏图离 `-1` 点越远，闭环越稳 → 用稳定裕度而非二值判断。
- **Tell**: 误差随级数按 `2a(1-a)` 收敛 → 复原机构在起作用。
- **Tell**: 系统越界后自动换参数并停在新稳定点 → 自行镇定机制生效。
- **Smell**: "多变量各自调 PID 就行" → 交叉耦合不会被对角增益消除，必须显式解耦。
- **Smell**: "采样周期随便设" → `F2*` 随 `t0` 周期性变化，增益上限与稳定裕度都随之改变。
- **Smell**: "用线性模型算继电器回路稳不稳" → 描述函数才是正确入口，且结论依赖输入振幅。
- **Tell**: 柯氏图中 `1/F1` 把整条 `-Fr` 曲线包住 → 该振幅下稳定；相交处即极限环。
- **Tell**: 搜索损失随试探振幅平方增长 → 想省损失只能靠过滤器把噪声压下去。

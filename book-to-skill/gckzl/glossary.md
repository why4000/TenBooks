# Glossary

**传递函数 (Transfer Function)** — 零初始条件下，系统输出与输入的拉氏变换之比 `F(s)=Y(s)/X(s)`，完整描述常系数线性系统的外部动态。

**拉氏变换 (Laplace Transform)** — 把时间域函数 `y(t)` 映射为复频域函数 `Y(s)` 的积分变换，把微分方程化为代数方程。

**极点 (Pole)** — 传递函数分母的根；极点位置决定系统的稳定性与响应速度，闭环极点全在 s 左半平面才稳定。

**反馈 (Feedback)** — 测量输出并与输入比较，用偏差信号驱动执行机构，使系统按误差自我纠正。

**偏差信号 (Error Signal)** — 输入与反馈量之差 `E(s)=X(s)-F2(s)Y(s)`，是反馈控制器的作用对象。

**乃氏判据 (Nyquist Criterion)** — 用开环频率特性在复平面上的轨迹绕 `-1` 点的圈数，判断闭环系统稳定性。

**路斯—胡尔维茨判据 (Routh–Hurwitz Criterion)** — 只用特征方程系数判断多项式根是否全在左半平面的代数稳定性判据。

**时滞 (Time Lag)** — 系统当前变化取决于过去某一时刻状态的时间延迟 `τ`，使传递函数出现 `e^{-sτ}`。

**微分差分方程 (Differential-Difference Equation)** — 同时含导数项与延迟项的运动方程，是时滞系统的数学描述。

**萨奇图 (Satche Diagram)** — 把含时滞的回路传递函数拆成 `g1(s)` 与 `g2(s)` 两条图线，用相对位置判断任意时滞下的稳定性。

**平稳随机过程 (Stationary Random Process)** — 统计性质不随时间平移改变的随机过程；工程中常以时间平均代替系集平均。

**相关函数 (Correlation Function)** — `R(τ)=E[y(t)y(t+τ)]`，描述随机过程不同时刻取值的关联程度。

**功率谱 (Power Spectrum)** — 相关函数的傅氏变换，描述随机信号能量随频率的分布。

**白噪声 (White Noise)** — 功率谱为常数、不同时刻取值互不相关的最"杂乱"随机过程。

**维纳—辛钦关系 (Wiener–Khinchin Relation)** — 相关函数与功率谱互为傅氏变换的一对关系式。

**描述函数 (Describing Function)** — 用非线性环节对基波的等效增益与相移近似其频率特性，用于判断极限环（原书称柯氏方法）。

**极限环 (Limit Cycle)** — 相平面上孤立的闭轨，对应系统无需外部周期驱动即可维持的自激振荡。

**自行镇定系统 (Self-Stabilizing System)** — 在相空间设开关边界，轨迹越界即切换参数，自动摈弃不稳定运动形式的系统。

**适应环境系统 (Adaptive System)** — 面对接连出现的干扰，连续调整参数、逐步扩展适应范围的系统。

**复合方法与复原机构 (Multiplexing & Restoring Organ)** — 冯·诺伊曼提出的可靠性结构：用多路线束、随机重排与再复合，把不可靠元件组合成可靠系统。

**解耦 (Decoupling)** — 通过设计控制矩阵，使每个被控制量只受自己的给定值支配，调节一路不再扰动另一路；原书称"不互相影响的控制"。

**反应方程 (Reaction Equation)** — 解耦条件满足后，每个被控制量与其给定值、扰动之间只剩单一回路关系，形式与单回路伺服完全平行。

**已调幅波 (Amplitude Modulation)** — 载波频率固定、振幅随信号变化的正弦波，是交流伺服系统与振荡控制伺服系统的共同信号形式。

**采样系统 (Sampled-Data System)** — 反馈开关只在等间隔采样时刻短暂闭合、其余时间断开的伺服系统；信号以离散时刻的值表示。

**施梯必茨—申南理论 (Stibitz–Shannon Theory)** — 把拉氏变换的积分换成对采样时刻求和，定义周期传递函数 `F2*(s)`，使采样系统理论获得与连续系统同形的方程与乃氏判据。

**柯氏方法 (Kochenburger Method)** — 用只与振幅有关、与频率无关的等效频率特性分析继电器等非线性环节，通过判断 `1/F1` 是否包围整条 `-Fr` 轨迹来定稳定性与极限环。

**相平面 (Phase Plane)** — 以输出量与其一阶导数为坐标的状态平面；二阶自持系统的全部运动可用一条带方向的曲线表示。

**颤震 (Chattering)** — 继电器伺服到达平衡点后，继电器仍继续动作，在原点附近形成的高频小幅振动。

**最优开关曲线 (Optimal Switching Curve)** — 相平面上把 +1 与 -1 两个控制区域分开的曲线；沿它切换可使系统以最短时间回到原点。

**变系数线性系统 (Variable-Coefficient Linear System)** — 线性微分方程的系数随时间（或随距离）变化的系统；齐次解衰减不能保证有输入时输出有界。

**摄动方程 (Perturbation Equation)** — 在已知正规轨迹附近对运动方程作一阶线性化所得的偏差量方程，其系数沿正规轨迹计算、一般为时变系数。

**伴随函数 (Adjoint Function)** — 满足原系统齐次方程的伴随（转置）方程的一组函数；借助布利斯基本公式把终端指标转写为沿途驱动量的加权积分。

**积分准则 (Integral Criterion)** — 把性能要求写成 `∫F(y,ẏ)dt` 取极小或取定值，再用拉格朗日乘子合成多个准则，是"指定性能再反解控制"的设计入口。

**搜索损失 (Search Loss)** — 极值搜索系统为把输出维持在最优运转点附近而付出的平均性能代价，近似随试探振幅的平方增长。

**平均平方误差 (Mean Square Error)** — `E[e²]`，最优过滤器的设计判据；它重罚大误差而几乎不罚小误差，对高度不对称的分布并不适用。

**维纳—阔尔莫果洛夫理论 (Wiener–Kolmogorov Theory)** — 用变分法使平均平方误差最小；把功率谱分解为左、右半平面两半，最优传递函数取极点全在左半平面的那一部分。

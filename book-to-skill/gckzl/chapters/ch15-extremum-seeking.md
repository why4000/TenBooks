# Chapter 15: 自动寻求最优运转点的控制系统

## Core Idea
前面各章都有一个前提：系统特性在设计前已知。这一章连它也去掉——制造公差、磨损、环境变化都会让特性偏离设计值，结冰扰动甚至无法预报。办法是“边运转边测量”：加小幅试探，观察输出响应，据此判断最优点方向并维持在附近。代价是输出围绕最优点摆动，产生搜索损失。

## Frameworks Introduced
- **基本概念与自动寻求原理**: 输出对输入在最优点附近近似为抛物线；令输入恒速上升，输出先增后减，`dy*/dt` 过零后达预定负阈值即反转输入，形成周期搜索。搜索周期 T、范围 D、损失 `D*=kD²/3`。
- **正弦试探的连续方案**: 输入叠加正弦分量，输出含二倍频项；滤波后与试探信号相乘再滤波，得正比于偏差的信号，使其按时间常数衰减。
- **干扰与动力学的影响**: 噪声谱在低频“飘移区”与高频区之间有一段安静带，试探频率应落在其中；输出分“可能输出”与“指示输出”，须计入两个线性部分的传递函数，且输出搜索周期是输入周期的一半。
- **自动保持最高点的系统**: 用电容器记忆输出峰值，当“峰值电压与实际指示电压之差”达临界值时反转输入；输出只有基频，不依赖微分，适合安静带很窄的系统。
- **稳定运转的设计**: 反转时把电容电压预置得略低，抑制虚假正电压差；临界电压差必须大于噪声振幅，否则会误反转。

## Key Concepts
- **搜索周期 / 搜索范围 / 搜索损失**: 三个核心设计量；损失是为“保持在最优点附近”付出的平均性能代价。
- **临界电压差**: 触发输入反转的阈值，直接受噪声限制。

## Mental Models
- 自寻最优像“蒙眼爬山”：看不到山顶，只能伸杖试探坡度。
- 搜索像“来回摆动的盲人杖”：摆幅太小测不出坡向，太大又偏离山顶。
- 搜索损失像“试探的学费”：想贴着最优点，就得接受围绕它的小幅摆动。

## Anti-patterns
- **Anti-pattern 1**: 把试探频率放在噪声最强的频段，信号被淹没。
- **Anti-pattern 2**: 用输出微分作控制信号，在高频噪声下微分把噪声放大。
- **Anti-pattern 3**: 搜索范围比噪声振幅还小，系统被噪声驱动着乱反转。

## Key Takeaways
1. 当对象特性不可预知或会漂移时，“在线测量”可以替代“事先建模”。
2. 核心折衷是搜索损失与抗噪能力：两者都由试探振幅与周期决定。
3. 峰值记忆式方案避免微分，适合安静带狭窄的场合，更为稳健。

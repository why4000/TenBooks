# Chapter 17: 自行镇定和适应环境的系统

## Core Idea
系统越复杂，元件失效与装配误差越难避免。与其试图预先设计一个"永远正确"的系统，不如设计一个"越界就换参数"的机制：系统在相空间里设一条可接受边界，轨迹一旦越界就切换参数，直到找到能回到稳定点的那一组。可靠性因此从"事先算准"变成"运行中搜索"。

## Frameworks Introduced
- **自行镇定系统 (Self-Stabilizing System)**: 在相空间设开关边界；轨迹碰到边界，参数 `λ` 跳到另一个值，系统自动摈弃不稳定运动形式。
- **随机参数搜索 (Random Parameter Search)**: 切换规律可以完全随机；只要参数集合中存在稳定形式，系统终会碰到它。
- **适应环境系统 (Adaptive System)**: 干扰接连出现时，系统连续尝试新的参数组合，逐步"理解"并适应更多工况。
- **多维推广**: 两个变量的相平面推广到 `n` 维相空间，边界变为 `n-1` 维超曲面。

## Key Concepts
- **阿施贝 homeostat**：四根磁铁、四个线圈、转换开关随机选参数；约 390,625 种运动形式，不稳定形式被自动淘汰。
- **可接受边界**：以原点为中心、对应 ±45° 转角的"立方体"；越界即触发切换。
- **稳定形式保留**：一旦进入稳定域，轨迹不再碰边界，开关不再动作，系统停在稳定状态。
- **"老练"**：第二次及以后的适应会改变参数，使系统对更多干扰具备抵抗力。

## Mental Models
- 自行镇定像保险丝+重启：不保证每个配置都对，但保证错误配置不会永久停留。
- 相空间边界像围栏：羊跑出围栏就换一片草地，直到找到能待住的那片。
- 随机搜索像掷骰子找钥匙：单次很笨，但只要钥匙在集合里，迟早能开锁。

## Anti-patterns
- **Anti-pattern 1**: 以为随机切换一定成功——若所有参数下都不稳定，机制无效。
- **Anti-pattern 2**: 边界设得太宽松，系统已严重偏离才切换。
- **Anti-pattern 3**: 把适应当成"一次学会"；适应是连续过程，干扰变化后需重新适应。

## Key Takeaways
1. 可靠性可以来自"结构性的试错机制"，而不只是精密设计。
2. 自行镇定的前提是：参数集合中至少存在一个稳定形式。
3. 适应环境的能力表现为"连续适应"，而非一次性最优。

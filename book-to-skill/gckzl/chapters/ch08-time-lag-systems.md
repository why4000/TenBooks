# Chapter 8: 有时滞的线性系统

## Core Idea
时滞不是"时间常数大一点"，而是系统此刻的变化取决于过去某一时刻的状态。数学上，微分方程变成微分差分方程，传递函数出现 `e^{-sτ}`；稳定裕度会被时滞悄悄吃掉，甚至使一个原本稳定的回路变成持续振荡。

## Frameworks Introduced
- **时滞 (Time Lag)**: 变量间关系涉及 `t` 与 `t-τ` 两个时刻；`τ` 为纯滞后。
- **微分差分方程 (Differential-Difference Equation)**: 时滞系统的运动方程；特征方程含 `e^{-sτ}`，有无穷多个根。
- **萨奇图 (Satche Diagram)**: 把回路传递函数拆成 `g1(s)` 与 `g2(s)`，`g1` 对应单位圆、`g2` 对应一条直线，用两条图线的相对位置判断任意时滞下的稳定性。
- **绝对稳定 (Unconditional Stability)**: 对任意 `τ` 都稳定的系统；火箭发动机设计中常被迫追求这一性质。

## Key Concepts
- **火箭燃烧时滞**：克洛克（Crocco）研究燃烧不稳定，喷入燃料到开始燃烧存在加热时滞；时滞与压力耦合会激发低频振荡。
- **临界时滞与临界频率**：使特征方程出现纯虚根的参数值，是稳定/不稳定的分界。
- **超越传递函数**：`F(s)=1/[s+(1-a)+ae^{-sτ}]`，不是多项式之比。

## Mental Models
- 时滞像"看着后视镜开车"：你纠正的是过去的偏差，越晚看到，越容易过度修正。
- 萨奇图像两把尺子：一把量回路本身，一把量延迟项，比较谁在谁外面。

## Anti-patterns
- **Anti-pattern 1**: 用无时滞模型调参，再直接上线到时滞系统。
- **Anti-pattern 2**: 只测稳态误差，忽略时滞引起的相位滞后。
- **Anti-pattern 3**: 假设时滞是常数；实际时滞常随工况变化。

## Key Takeaways
1. 时滞改变相位、不改变稳态增益，是稳定性的隐形杀手。
2. 时滞系统的特征方程是超越方程，不能只靠有限个极点判断。
3. 若时滞不确定，应设计"对任意时滞都稳定"的绝对稳定系统，或降低环路增益换取裕度。

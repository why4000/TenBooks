# Chapter 14: 满足指定积分条件的控制设计

## Core Idea
前面各章是“先假定结构、再看性能”；这一章反转：先把希望的性能写成对时间的积分（取极小或取定值），再用拉格朗日乘子把多准则合成一个变分问题，解出欧拉—拉格朗日方程，最后由计算机实时实现。所得系统通常非线性——这不是缺陷，而是为逼近最优性能有意为之。

## Frameworks Introduced
- **控制的准则与稳定性问题**: 性能写成 `∫F(y,ẏ)dt = const 或 min`，如误差平方积分、过渡时间积分等；稳定性作为特殊准则，过渡中不参与设计，另加只在结束时起作用的稳定装置，构成多方式控制。
- **一阶系统的一般理论与工程实现**: 用乘子 λ 把约束并入被积函数，得欧拉—拉格朗日方程；因 F 不显含 t，存在第一积分，可把两个边界条件合并为一个方程。实现时由测量机构取 N、T，计算机按控制方程产生燃料速率信号；误差足够小时断开计算机、切入稳定装置。
- **向多变量推广**: 二阶系统（两个自由度）对应三阶与四阶方程，配相应边界条件与第一积分；以微分方程作附加条件时乘子变成时变 λ(t)，y、z、λ 由控制方程、固有方程与变分条件确定。
- **控制设计概念的比较**: 老方法给出线性系统、可用电阻电容实现；新方法给出非线性计算机系统、性能最优，但须事先知道准则。

## Key Concepts
- **拉格朗日乘子 (Lagrange Multiplier)**: 把“某个积分等于定值”的约束并入极值问题；λ=0 表示该准则被放弃。
- **欧拉—拉格朗日方程 (Euler–Lagrange Equation)**: 变分问题的驻值条件，是控制方程的本体。
- **多方式控制 (Multi-Mode Control)**: 过渡期按最优准则运行，终了期切入稳定装置。

## Mental Models
- 指定积分条件像“给定油耗预算，求最快到达”：约束与目标写进一个泛函。
- 控制计算机像“把变分方程翻译成实时指令”的翻译器。

## Anti-patterns
- **Anti-pattern 1**: 只用速率误差一个准则，解出 `N≡Ns`，要求温度无限升高，不可实现。
- **Anti-pattern 2**: 写出漂亮变分方程却不查边界条件与积分常数，得到不可实现的解。
- **Anti-pattern 3**: 忘记终了期的稳定装置，系统停在最优点却无法保持。

## Key Takeaways
1. 性能一旦能用积分精确表述，就可反解出控制方程，而不必事先猜结构。
2. 多准则通过乘子合成，λ 的取值就是性能之间的折衷比例。
3. 新方法必然更复杂：控制装置从电阻电容线路升级为非线性计算机，这是换取最优性的代价。

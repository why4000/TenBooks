# Chapter 9: 平稳随机输入下的线性系统

## Core Idea
很多输入根本无法用确定的时间函数描述：大气湍流、噪声、起伏信号。此时设计目标从"让输出等于某条轨迹"改成"让输出的统计性质合格"。只要知道输入的相关函数或功率谱，线性系统的输出统计量就可以算出来。

## Frameworks Introduced
- **平稳随机过程 (Stationary Random Process)**: 统计性质不随时间平移改变；系集平均等于时间平均（各态历经假设）。
- **相关函数 (Correlation Function)**: `R(τ)=E[y(t)y(t+τ)]`，描述不同时刻取值的关联程度。
- **功率谱 (Power Spectrum)**: 相关函数的傅氏变换；由维纳—辛钦关系与相关函数互换。
- **线性系统随机响应**: 输出功率谱 `Φ_y(ω)=|F(iω)|²Φ_x(ω)`。

## Key Concepts
- **系集与元素**：大量相同系统的总体；用系集平均定义概率分布。
- **白噪声 (White Noise)**：相关函数为冲激、功率谱为常数的最"杂乱"随机过程。
- **高斯过程**：相关函数为高斯曲线时，功率谱也为高斯形；工程中常用来近似湍流。
- **概率估计**：即使只知道统计特性，也能对输出偏离平均值的概率给出上界。

## Mental Models
- 随机输入像人群噪声：听不清每个人说什么，但能测出整体声压级和频谱。
- 功率谱像均衡器：告诉你能量分布在哪些频段，系统再按 `|F(iω)|²` 选择性放大或衰减。
- 相关函数像记忆长度：`R(τ)` 衰减越快，系统越"健忘"，越接近白噪声。

## Anti-patterns
- **Anti-pattern 1**: 用一条实测轨迹代表整个随机输入，忽略统计分布。
- **Anti-pattern 2**: 只约束输出的均值，不约束方差/功率谱。
- **Anti-pattern 3**: 把非平稳过程（如突变载荷）硬套平稳理论。

## Key Takeaways
1. 随机输入下，系统设计是"统计设计"，不是"轨迹跟踪"。
2. 相关函数与功率谱是同一信息的两种语言，按计算方便选用。
3. 线性系统对随机输入的整形能力，完全由 `|F(iω)|²` 决定。

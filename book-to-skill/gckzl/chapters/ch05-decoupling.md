# Chapter 5: 不互相影响的控制

## Core Idea
多个被控制量互相牵动时，调一个量必然扰动另一个量，单回路设计失效。钱学森把“不互相影响”提升为与稳定性、快速性并列的新准则；对象、伺服、测量视为固定，唯有控制矩阵 `C` 可选，问题化为使系统矩阵对角线化。

## Frameworks Introduced
- **单变数系统的控制 (Single-Variable Control)**: 对象 `E`、测量 `L`、伺服马达 `S`、控制 `C` 串成回路，另加扰动 `V`；与第四章只差一个扰动入口。
- **多变数系统的控制 (Multi-Variable Control)**: 输出 `Y` 与输入 `W` 由矩阵 `E` 联系；输入常多于输出，多出来的输入也按预定值控制。
- **不互相影响的条件 (Non-Interaction Condition)**: 对每个被控制量 g，非对角元素或为零，或由对角元素与 `E*` 的余因式之比确定；勃克森包姆与胡德证明这既是必要也是充分条件。
- **反应方程 (Reaction Equation)**: 条件满足后，每个量只受自身给定值与扰动支配，形式与单回路平行。

## Key Concepts
- **发动机矩阵 (Engine Matrix)**: 传递函数按行列排成的表；输入从列进、输出从行出。
- **对角线化 (Diagonalization)**: 把耦合的系统矩阵化为只保留主对角项，是解耦的数学实质。
- **涡轮螺旋桨发动机**: 转速、进气温度、桨叶角、喷油速率四个变量；矩阵只含一个时间常数，其余由控制、伺服、测量引入。
- **有补充燃烧的涡轮喷气发动机**: 转速、两处喷油速率、尾喷管开口面积；让尾喷管开口随其余变量变化，是解耦成立的关键。

## Mental Models
- 解耦像理一团缠绕的线：不剪断，而是给每根线配一个只认自己的拉线人。
- 控制矩阵像调音台的交叉推子：主推子定本通道增益，交叉推子抵消串音。
- 尾喷管开口像“随动补偿器”：不直接控转速，却通过改变流通面积替其他回路卸掉耦合。

## Anti-patterns
- **Anti-pattern 1**: 只调各回路的对角增益，不管交叉项，指望“调着调着就不耦合了”。
- **Anti-pattern 2**: 以为被控制量个数必须等于输入个数；原书恰恰讨论输入多于输出的情形。
- **Anti-pattern 3**: 把对象特性、伺服、测量也当作可自由改动的设计变量。

## Key Takeaways
1. 多变量耦合是结构性问题，单回路调参解决不了，必须显式设计控制矩阵。
2. 条件只确定非对角与对角元素之比；对角元素仍可按第四章方法自由设计。
3. 顺序是：先按单回路准则定对角控制传递函数，再用解耦条件填非对角项。

# Chapter 13: 利用摄动理论的控制设计

## Core Idea
远程火箭实际弹道与“正规弹道”只差很小，偏差可一阶线性化，得变系数的摄动方程。弹道摄动理论原用于算改正量，钱学森把它翻转为控制设计工具：用布利斯的伴随函数把射程偏差表示成各扰动量的加权积分，于是关车时刻与升降舵改正都能写成可实时比较的判据，由弹上与地面的计算机协同完成。

## Frameworks Introduced
- **火箭运动方程与摄动方程 (Perturbation Equations)**: 随地球自转，用半径与经度差描述位置，共六个一阶方程；实际量写成“正规值 + δ”，只保留一阶项，得六个偏差量的变系数线性方程组。
- **伴随函数 (Adjoint Function)**: 满足齐次伴随方程的一组 λ(t)；布利斯基本公式把“偏差量加权和”与“驱动量加权积分”联系起来，由着陆时刻的终点条件定出射程偏差。
- **关车条件**: 射程偏差拆成“时刻项”与“积分项”；前者化为关车时比较 J 与 J*，相等即关机。
- **导航条件**: 要求被积函数恒为零，得一组系数 d5…d8；结合跟踪站测得的 A、B、C 与弹上测得的大气偏差，解出升降舵改正量。
- **导航系统与控制计算机**: 储存数据（正规弹道、伴随函数、系数）+ 关车计算机 + 导航计算机 + 升降舵伺服；模拟机简单实时但受间隙、噪声与精度限制；数字机精度高，却有离散输出与计算时滞。

## Key Concepts
- **正规弹道**: 标准火箭、标准大气、给定升降舵程序算出的基准弹道。
- **射程 (Range)**: 发射点与着陆点的距离，是本章唯一的性能指标。

## Mental Models
- 摄动像“在已知标线上量偏差”：不重算整条曲线，只算偏离标线的那一小段。
- 伴随函数像“从终点倒推的敏感度权重”：告诉你此刻哪个偏差最影响落点。
- 导航计算机像“边飞边改的瞄准具”：不断把实测偏差折算成舵面改正。

## Anti-patterns
- **Anti-pattern 1**: 用低速航行器的运动学思路操纵高速火箭，忽略惯性动力学。
- **Anti-pattern 2**: 只在地面算一次弹道就发射，不设实时改正回路。
- **Anti-pattern 3**: 选用数字计算机却不评估计算时滞对高动态对象的影响。

## Key Takeaways
1. 变系数系统的控制设计可以“围绕已知基准轨迹”线性化，把难题化为偏差量的一阶问题。
2. 伴随函数把终端指标（射程）转写成沿途可测的加权积分，是实时判据的来源。
3. 系统本质仍是反馈伺服，只是反馈信号由跟踪站与计算机生成。

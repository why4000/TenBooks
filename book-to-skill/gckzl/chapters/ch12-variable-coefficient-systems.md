# Chapter 12: 变系数线性系统

## Core Idea
火箭弹在燃烧过程中质量、气动条件都在变，运动方程线性化后系数不再是常数。这一章的核心是一个否定性结论：常系数系统“只看齐次解是否衰减”的经验，对变系数系统不成立——即使所有补充函数都衰减，某些输入仍可让输出无限增大。因此必须先说明输入是什么，才能谈运转状态好坏；这个“先定输入”的做法正是下一章摄动设计的入口。

## Frameworks Introduced
- **火箭弹的运动状态与线性化方程**: 沿弹道、垂直弹道、绕横轴转动三个方程；推力 S 为常数，重心与推力线有偏差角 δ。推力远大于重力与阻力，第零次近似是等加速直线弹道；在它附近取一阶偏差，得到以距离 z 为自变数的变系数线性方程。
- **无量纲化与贝塞尔方程**: 引入特征长度与无量纲距离 ξ，把冲角方程化为贝塞尔方程标准形；其补充函数可用正弦型初等函数表示。
- **火箭弹的稳定性**: 由六个“火箭函数” G 表示各类初始扰动的影响；ξ 很大时这些函数趋于非零常数，其中一项还会无限增大，按第四章准则火箭弹是不稳定的。
- **火箭函数与福来内尔积分 (Rocket Functions / Fresnel Integral)**: 罗色尔等人给出的函数族，由含变量半次幂的正弦/余弦积分组成，并制成了函数表。

## Key Concepts
- **特征长度 / 扰动波长**: 由推力、转动惯量等组合出的长度量纲参数，标识扰动在弹道上起伏的尺度。
- **火箭函数 (Rocket Functions)**: 描述初始扰动影响的六个函数，是变系数方程解的具体形式。
- **自变数替换**: 用距离代替时间不改变稳定性判断，因为距离随时间单调增。

## Mental Models
- 变系数系统像“边跑边换鞋”：每一步的方程都换了，不能用起跑时的鞋码判断全程。
- 补充函数衰减像“影子变短”：看似收敛，驱动项一来输出仍可能跑掉。
- 稳定性问题像先问“路况”：不说清输入，就无法回答车稳不稳。

## Anti-patterns
- **Anti-pattern 1**: 直接搬用常系数系统的稳定性经验到变系数系统。
- **Anti-pattern 2**: 看到齐次解衰减就断言系统输出有界。
- **Anti-pattern 3**: 在火箭这类短时高速过程中，仍用“先分析稳定性、再谈性能”的旧顺序。

## Key Takeaways
1. 变系数系统的响应依赖输入的具体形式，“一般稳定性”提法本身不成立。
2. 贝塞尔函数衰减容易误导，必须连同驱动项判断。
3. 正确出路是放弃一般稳定性问题，改为针对指定输入与指定性能做设计——即摄动理论。

## Connects To

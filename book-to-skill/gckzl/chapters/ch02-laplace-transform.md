# Chapter 2: 拉氏变换法

## Core Idea
拉氏变换不是新的物理理论，而是一次"翻译"：把时间域里的微分方程翻译成复频域里的代数方程。翻译之后，微分、积分变成乘、除，初值问题被系统地纳入同一个框架，求解过程因此标准化。

## Frameworks Introduced
- **拉氏变换 (Laplace Transform)**: `Y(s)=∫₀^∞ e^{-st}y(t)dt`，其中 `s` 为复变数；反变换由反转公式给出。
- **初值问题 (Initial-Value Problem)**: 给定 `t=0` 的状态与 `t>0` 的驱动函数，求系统运动。
- **传递函数雏形 (Transfer Function)**: 零初始条件下，输出变换与输入变换之比 `Y(s)/X(s)=1/D(s)`。

## Key Concepts
- **补充函数与特解**：解可拆成"由初始条件决定的部分"与"由驱动函数决定的部分"。
- **拉氏变换表**：常用函数对制成"字典"，避免每次做复杂反变换积分。
- **单位冲量响应**：冲量输入下的输出，是传递函数的时域对应物。
- **正弦驱动**：频域分析的基础，引出频率特性。

## Mental Models
- "t 的语言"与"s 的语言"：前者用微积分描述过程，后者用代数运算描述同一过程。
- 变换像换汇率：不改变价值，只改变计算方式；最后还要换回时间域才能解释物理结果。

## Anti-patterns
- **Anti-pattern 1**: 把 `s` 当成真实物理频率；`s` 是复变数，只有 `s=iω` 时才对应稳态频率响应。
- **Anti-pattern 2**: 忘记初始条件；初值不为零时，输出里会多出补充函数项。
- **Anti-pattern 3**: 对不满足存在条件的函数硬套变换。

## Key Takeaways
1. 拉氏变换把微分方程化为代数方程，是后续传递函数方法的入口。
2. 零初始条件下，系统特性完全由 `1/D(s)` 决定。
3. 变换表与反转公式是同一工具的两端：前者查表，后者兜底。

# Chapter 18: 误差的控制

## Core Idea
上一章用"越界换参数"对付不可预料的失效；本章反过来：故意把误差引进系统，再设计一种结构，使系统在元件不可靠的前提下仍能给出可靠输出。核心结论是：简单并联只能防"没有输出"，防不了"输出错了"；必须用多重化、随机重排与复原机构，才能把错误率压到任意低。

## Frameworks Introduced
- **冗余 (Redundancy)**: 用多个元件并行工作，降低整体失效概率。
- **复合方法 (Multiplexing / von Neumann)**: 把一路信号扩成 `n` 根线束，经谢弗元件网络后，以置信水平 `δ` 判定整体输出。
- **复原机构 (Restoring Organ)**: 把输出线束复制、随机配对、再过一级谢弗元件，抵消误差扩散。
- **错误阈值 0.618**: 两级复原机构后，激发概率 `a` 的迭代为 `a' = 2a(1-a)`；当 `a<0.618` 时误差收敛。

## Key Concepts
- **失效类型**：无输出 vs 错误输出；后者更危险，因为错误信号混入正确信号仍是错误。
- **谢弗元件 (Sheffer Stroke)**：单一基本逻辑元件，可构成与、或、非，便于统一分析误差。
- **置信水平 δ**：线束中超过 `(1-δ)n` 根线一致，才判定整体为开/关。
- **误差扩散**：简单复合可能让输出误差等于输入误差之和，因此需要复原机构。

## Mental Models
- 冗余像多路投票：不是"多买几台机器"，而是"让多台机器按纠错规则投票"。
- 复原机构像洗牌：把相关的错误打散，避免同一错误在输出中成簇。
- 0.618 像安全水位：低于它，误差在每级之后缩小；高于它，误差被放大。

## Anti-patterns
- **Anti-pattern 1**: 用简单并联解决"错误输出"——失效概率不降反不降。
- **Anti-pattern 2**: 增加冗余却不做随机重排，错误仍然相关。
- **Anti-pattern 3**: 假设元件错误独立，却忽略共因失效。

## Key Takeaways
1. 误差控制的关键不是"元件更多"，而是"组合方式更聪明"。
2. 只要单件错误率低于阈值，多级复合可把系统错误率降到任意低。
3. 可靠性设计需要区分"缺失"与"错误"，二者对策不同。

# Cheatsheet: 理解媒介——从对象到现象

## Decision Rules

| When you see... | Do this | Because... |
|---|---|---|
| A study treats media as neutral carriers | Apply 对象→现象还原 | Carriers are abstractions from lived experience |
| "万物皆媒" conclusion | Suspect the objectivist premise | If everything is media, nothing is media |
| Claims of "transparent" communication | Run 厚度分析 | Complete transparency abolishes media |
| Body mentioned as "factor" or "variable" | Reframe as 元媒介 | The body is the ground, not a variable |
| Form vs content debate | Use 双重否定→双重肯定 | Media are content-bearing form |

## Key Thresholds & Defaults

- **默认立场**: 现象媒介先于对象媒介 (phenomenal media is primary).
- **不可还原项**: 身体的厚度 (bodily thickness) — never assume it can be eliminated.
- **方法默认**: 现象学还原 first, empirical analysis second.

## Tells & Smells

- **Smell**: "媒介即工具" — instrumentalism misses expressivity.
- **Smell**: "客观 vs 主观" framing — the dichotomy itself is the problem.
- **Smell**: "数据证明" applied to media meaning — meaning is phenomenal, not just measurable.
- **Tell**: When a medium's "effect" can't be separated from how it's experienced — you've hit 现象媒介.

## Feature Quick Reference

| Feature | Pair | Core Claim |
|---|---|---|
| 含混性/规范性 | 载体↔内容 | 既非纯载体也非纯内容 |
| 意向性/对象性 | 意识↔对象 | 对象媒介是身体意向的沉淀 |
| 象征性/表达性 | 指涉↔创造 | 媒介即意义，即存有 |
| 情境性/普遍性 | 具体↔普遍 | 情境中生成，预设普遍视域 |
| 主体性/主体间性 | 建构↔交流 | 媒介建构现实，互主体性奠基交流 |

身体(元媒介) → 具身化 → 现象媒介 → 五重特征

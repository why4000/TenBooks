# Patterns

## Pattern 1: 对象→现象还原 (Object-to-Phenomenon Reduction)
**When to use**: When a media concept is treated as a self-evident object but seems to lead to paradoxes (e.g., "万物皆媒").

**How**:
1. Identify the object-form of the media concept.
2. Ask: what lived bodily experience does this object presuppose?
3. Trace the object back to its phenomenal origin.
4. Re-describe the concept in phenomenal terms.

**Trade-offs**: This is a philosophical/analytic move, not an empirical one. It deepens understanding but does not by itself produce measurable results.

## Pattern 2: 身体局限→媒介发明 (Body Limitation → Media Invention)
**When to use**: When analyzing why a particular medium emerged or what need it serves.

**How**:
1. Identify the bodily limitation (distance, time, perceptual range, memory).
2. Describe the medium as the extension that overcomes it.
3. Note the complementarity: the extension creates something new that did not exist before.

**Trade-offs**: Functional explanations risk oversimplifying media that have multiple, overlapping functions.

## Pattern 3: 双重否定→双重肯定 (Double Negation → Double Affirmation)
**When to use**: When a concept seems to fall between two opposed categories (neither A nor B).

**How**:
1. State what the concept is NOT (double negation).
2. Affirm the original unity that both abstractions derive from.
3. Treat the unity as normative, not merely descriptive.

**Trade-offs**: This dialectical move can feel like "having it both ways"; it requires showing the original unity concretely.

## Pattern 4: 厚度分析 (Thickness Analysis)
**When to use**: When someone claims a technology will make communication "transparent" or "frictionless".

**How**:
1. Identify the bodily "thickness" the medium presupposes.
2. Show that complete transparency would abolish the medium itself.
3. Conclude that some opacity is constitutive, not a defect to be eliminated.

**Trade-offs**: This pattern counters techno-optimism but can seem conservative if not paired with concrete analysis of what specific thickness matters.

## Pattern 5: 情境-普遍辩证 (Situated-Universal Dialectic)
**When to use**: When balancing context-specific media analysis with general theory.

**How**:
1. Ground the analysis in a concrete situation.
2. Identify the universal horizon that the situation presupposes.
3. Show how the medium both responds to the situation and reveals the universal.

**Trade-offs**: Requires care to avoid either relativism (only situation) or empty universalism (no situation).

# Chapter 2: 公理化思维——人类理性思维的顶级智慧

## Core Idea
公理化思维是第一性原理的方法论典范：从最少的不证自明的公理出发，通过演绎法推导出整个知识体系。欧几里得《几何原本》是其原型。

## Frameworks Introduced
- **公理化思维 (Axiomatic Thinking)**: 选择一组公理（不证自明的前提），通过演绎推理构建整个体系。
  - When to use: 当需要为一个领域建立严格的逻辑基础时。
- **欧几里得几何**: 从5条公理+5条公设推导出465个命题。一切学问都是证明系统。

## Key Concepts
- **公理**: 不证自明、无法在系统内证明的前提。
- **证明系统**: 从公理出发，每一步都可追溯到公理的体系。

## Mental Models
- 公理化思维 = "先打地基，再盖楼"——地基是公理，楼是推导的结论。
- 哲学和科学的根基都是公理化思维。

## Key Takeaways
1. 公理化思维是人类理性思维的顶级形式。
2. 公理来自系统之外，是第一性原理的具体体现。
3. 公理化思维可应用于商业战略等非数学领域。

# Chapter 1: 第一性原理——任何理性系统的根基性命题

## Core Idea
任何理性系统都建立在一个来自系统之外的基石假设之上，这个基石就是第一性原理。归纳法无法提供它（只能证伪），演绎法需要它作为前提。

## Frameworks Introduced
- **归纳法 (Induction)**: 从实践推导结论，推广到一切时空。隐含假设是"连续性假设"——未来与过去连续。
  - 空间性归纳: 某地看到的天鹅都是白的→所有天鹅都是白的
  - 时间性归纳: 过去太阳升起→未来太阳升起
- **演绎法 (Deduction)**: 从前提通过三段论推导结论。隐含假设是"前提的准确性"。逻辑比事实更真实。
- **第一性原理**: 演绎法的终极前提，来自系统之外，不证自明。= 逻辑奇点 = 基石假设。

## Key Concepts
- **连续性假设**: 归纳法的隐含前提，未经证明。
- **求存不求真**: 归纳法的阿喀琉斯之踵——它帮助生存，但不保证真理。
- **基石假设**: 系统之外的前提，不是系统内的结论。

## Mental Models
- 任何系统像一座建筑，第一性原理是地基；看不见但决定一切。
- 归纳法是"在已有经验上外推"，演绎法是"从根上重新推导"。

## Anti-patterns
- 把系统内的结论当作第一性原理（循环论证）。
- 迷信归纳法的"证明"——归纳法只能证伪，不能证明。

## Key Takeaways
1. 归纳法依赖连续性假设，只能证伪不能证明。
2. 演绎法需要准确前提，前提来自系统之外。
3. 第一性原理是理性系统的根基性命题。

# Chapter 3: 破界创新——打破基石，边界外延

## Core Idea
破界创新不是在原有系统内改良，而是打破原有系统的基石假设，建立更广阔的新基石，在新基石上重建系统。

## Frameworks Introduced
- **破界创新三部曲**:
  1. 打破原有的基石假设（识别并质疑隐含前提）
  2. 定义新的基石假设（建立更根本的新前提）
  3. 在新基石上重建系统（从新前提出发演绎新体系）
- **难点**: 识别基石假设——它太习以为常，"看不见"。

## Key Concepts
- **隐含假设**: 系统中未被审视的前提。
- **边界外延**: 新基石比旧基石更广阔，系统边界因此扩大。

## Worked Example
- **IBM**: 从"计算机是大型企业的工具"到"计算机是个人工具"——基石假设的转换。
- **乔布斯/苹果**: 从"手机是通讯工具"到"手机是移动计算平台"。

## Key Takeaways
1. 破界创新的关键是识别并打破基石假设。
2. 新基石必须比旧基石更根本、更广阔。
3. 难点不在建立新系统，而在看见旧假设。

# Chapter 5: 第一创新——基于第一性原理进行创新

## Core Idea
从归纳创新转向演绎创新：不依赖经验归纳，而是从第一性原理演绎出新可能性。马斯克和芒格是典范。

## Frameworks Introduced
- **第一创新 (First Innovation)**: 基于第一性原理的创新，从根上重新推导，而非在已有方案上改良。
- **归纳创新 vs 演绎创新**: 归纳创新=经验+改良；演绎创新=第一性原理+重新推导。
- **查理·芒格的多元思维模型**: 掌握多个学科的基础模型（第一性原理），组合使用。

## Worked Example
- **马斯克 SpaceX**: 火箭成本高→拆解到原材料成本→发现可以自建→大幅降低成本。
- **马斯克 Tesla**: 电动车电池贵→拆解到原材料成本→重新设计电池组。

## Key Takeaways
1. 第一创新从第一性原理出发，不从既有方案出发。
2. 多元思维模型是跨学科第一性原理的组合。
3. 拆解到基本要素，重新组合，是第一创新的操作方法。

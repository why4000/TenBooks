# Chapter 4: 组织刷新——使命—战略的破界创新

## Core Idea
组织的破界创新从刷新使命开始，进而刷新文化和战略。纳德拉带领微软的转型是典范。

## Frameworks Introduced
- **组织刷新三步**: 刷新使命 → 刷新文化 → 刷新战略
- **鲍尔默时代的迷失**: 微软在"Windows优先"的基石假设下错失移动互联网。
- **纳德拉刷新**: 使命从"每个家庭都有PC"到"赋能全球每一个人和每一个组织"。

## Key Concepts
- **使命决定战略**: 使命是组织的第一性原理，战略是其演绎结果。
- **文化刷新**: 从"无所不知"到"无所不学"（learn-it-all vs know-it-all）。

## Key Takeaways
1. 组织转型的根在使命，不在战略战术。
2. 文化是使命的日常体现。
3. 战略必须随使命刷新而重建。

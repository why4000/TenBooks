# Patterns

## Pattern 1: 第一性原理推导 (First-Principles Deduction)
**When to use**: 当需要从根本上重新思考一个问题，而非在既有方案上改良时。

**How**:
1. 界定问题所在的系统。
2. 识别该系统的基石假设（第一性原理）。
3. 拆解问题到基本要素（不可再分）。
4. 从基本要素出发，重新组合推导。
5. 检验推导结果的逻辑三洽。

**Trade-offs**: 比归纳创新慢，但能突破路径依赖。

## Pattern 2: 破界创新三步 (Boundary-Breaking 3-Step)
**When to use**: 当现有系统的改良已达极限，需要根本性突破时。

**How**:
1. 打破原有的基石假设：列出所有"理所当然"的前提，逐一质疑。
2. 定义新的基石假设：找到更根本、更广阔的前提。
3. 在新基石上重建系统：从新前提出发演绎新体系。

**Trade-offs**: 风险高（新基石可能错误），但回报大（边界外延）。

## Pattern 3: 识别隐含假设 (Identify Implicit Assumptions)
**When to use**: 当系统出现悖论或无法解决的问题时。

**How**:
1. 问"这个系统认为什么是理所当然的？"
2. 列出所有未被审视的前提。
3. 对每个前提问"如果它不成立，会怎样？"
4. 找到导致悖论的那个前提。

**Trade-offs**: 需要勇气质疑根深蒂固的信念。

## Pattern 4: 逻辑三洽检验 (Three-fold Coherence Check)
**When to use**: 检验一个理论或信念是否可靠时。

**How**:
1. 自洽：检查内部是否有矛盾。
2. 他洽：检查是否与其他公认理论冲突。
3. 续洽：检查是否能解释新出现的事实。

**Trade-offs**: 三洽都通过仍不等于绝对真理，但已很高可靠。

## Pattern 5: 反从众思维 (Anti-herd Thinking)
**When to use**: 当一个观点仅仅因为"所有人都这么认为"而被接受时。

**How**:
1. 识别群体信念。
2. 问：这个信念有事实/逻辑支撑吗？还是仅仅因为从众？
3. 用第一性原理重新推导。
4. 承受孤独——真理往往在少数人手中。

**Trade-offs**: 反共识可能错误，需用逻辑三洽验证。

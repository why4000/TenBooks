# Cheatsheet: 第一性原理

## Decision Rules

| When you see... | Do this | Because... |
|---|---|---|
| "大家都这么做" | 用反从众思维检验 | 从众≠真理 |
| 在旧方案上改良无效 | 尝试破界创新 | 需要打破基石假设 |
| 成本/效率问题 | 拆解到基本要素重新推导 | 第一性原理创新 |
| 一个理论无法解释新事实 | 检查逻辑三洽之续洽 | 理论可能需要升级 |
| "这是理所当然的" | 识别隐含假设 | 基石假设往往看不见 |

## 破界创新三部曲
```
1. 打破旧基石假设  →  "我们一直认为X理所当然，但X真的成立吗？"
2. 定义新基石假设  →  "比X更根本的前提是什么？"
3. 重建系统        →  "从新前提出发，体系应该是什么样？"
```

## 逻辑三洽快速检验
- 自洽: 内部有矛盾吗？
- 他洽: 和其他公认理论冲突吗？
- 续洽: 能解释最新的事实吗？

## 归纳 vs 演绎 速查
| | 归纳法 | 演绎法 |
|---|---|---|
| 方向 | 实践→结论 | 前提→结论 |
| 隐含假设 | 连续性假设 | 前提准确 |
| 能力 | 只能证伪 | 可证明（前提对） |
| 典型问题 | 黑天鹅 | 前提错误则全错 |

## 关键阈值
- **第一性原理必须在系统之外** — 系统内的结论不是第一性原理。
- **新基石必须比旧基石更广阔** — 否则不是破界，只是修改。
- **反共识需要逻辑三洽** — 否则只是逆反。

## Tells & Smells
- **Smell**: "以前一直这么做" → 连续性假设的信号。
- **Smell**: "所有人都知道" → 从众效应的信号。
- **Smell**: "这是常识" → 隐含假设未被审视。
- **Tell**: 拆解到基本要素后发现成本远低于市场价 → 第一创新的机会。

# Chapter 5: 外行领导好莱坞

## Core Idea
升任执行副总裁后，艾格被派往洛杉矶负责 ABC 娱乐——一个他完全不懂的圈子：没拍过电视剧，不认识大人物，而且位置还很高。他的入场方法只有一条：不让自尊心占上风，抑制假装内行的冲动，多向对方提问。结果是《成长的烦恼》《美国家庭滑稽录像》和《双峰镇》(Twin Peaks)。

## Frameworks Introduced
- **外行领导入场 (Outsider Leadership Entry)**: 高位外行最大的风险是假装内行；承认不懂+提问式学习，反而最快建立判断与人脉。

## Key Concepts
- **核心心法**: "我的任务就是不要让自尊心占了上风，我要做的并不是使劲浑身解数给桌子对面的人留下一个好印象，而是抑制住假装知道自己在做什么的冲动，并多向对方提问。"他承认"我格格不入，这是无法掩盖的事实"。
- **位置很高+外行=最难的实事求是**: 一个人想实事求是已不易，位置很高还实事求是更困难。
- **快速学习、快速识人**: 到了以后快速学习，赶紧跟所有人认识。
- **作品清单**: 选择拍摄《成长的烦恼》；创造至今热播的《美国家庭滑稽录像》。
- **《双峰镇》的拍板**: 鬼才导演大卫·林奇 (David Lynch) 要用电影手法拍电视剧，剧本艾格没看懂——"这剧本我反正也看不懂"，但他向老板保证"这个剧拍出来肯定跟别的电视剧不一样"。拍板，大获成功。
- **做事进圈子**: 与林奇合作成功后，斯皮尔伯格 (Spielberg) 和乔治·卢卡斯 (George Lucas) 纷纷找上门。混进封闭圈子最有效的方法不是请客送礼吃饭，而是做事——你做事被他们看到，自然就进去了。
- **失败的学费**: 外行也有惨败，《警察摇滚》（警察唱摇滚执法）成为好莱坞笑柄。他让经理收视率高就打电话、低就发传真——半夜传真机响起，一切尽在不言中。

## Mental Models
- 承认不懂是学习的起点，假装懂是学习的终点。
- 可以不懂剧本，但必须能判断"差异化"——不懂细节不等于不能拍板。
- 作品是最好的社交货币：做一部不一样的剧，胜过一百顿饭局。
- 容忍个别失败，不因此停止拍板。

## Anti-patterns
- 使劲浑身解数给对面留好印象，假装知道自己在做什么。
- 靠请客、送礼、吃饭混圈子。
- 因一次惨败（《警察摇滚》）就不敢再拍板。

## Key Takeaways
1. 高位外行入场的第一件事：管理自尊心。
2. 提问式学习比展示自己更快建立判断。
3. 拍板的依据可以是"确定性差异"，而非对细节的完全掌握。
4. 用做事被看到的方式，自然进入封闭圈子。

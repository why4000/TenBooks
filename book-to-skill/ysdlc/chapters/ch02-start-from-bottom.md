# Chapter 2: 从底层起步

## Core Idea
所有人都是从最底层开始做工作的，区别在于你赋予这份工作的意义。艾格出身普通工薪家庭，靠叔叔病友的一条偶然人脉挤进 ABC，名义上是"部门工作室主管"，实际是场工。他对每一份琐碎工作都投入不一样的热情，这正是他后来被看见的根基。

## Frameworks Introduced
- **赋予工作意义 (Meaning-Making from the Bottom)**: 工作无大小，意义由自己赋予；投入度与专注度是区分人的分水岭。

## Key Concepts
- **出身**: 父亲爱看书、参加读书俱乐部，家里从不缺书；后父亲患狂躁症失业，家境拮据，艾格从小穿打补丁的裤子上学，考上伊萨卡学院 (Ithaca College)，毕业后做天气预报员。
- **偶然的人脉**: 叔叔住院，同病房的 ABC 低层员工为了面子"指挥工作"，叔叔顺嘴说侄子找工作——那人硬是把他塞进了 ABC。1974 年，周薪 150 美元。
- **场工日常**: 负责置景、工作餐、安排灯光，每天早上 4:30 准时到影棚把一切收拾好；其间受到特别多欺压和屈辱。
- **辛纳屈漱口水**: 1974 年弗兰克·辛纳屈 (Frank Sinatra) 演唱会，他的任务是买漱口水——"一路跑着去跑着回来"。辛纳屈让他进去，给了 100 美元小费，还送每位工作人员一个印着名字的镀金打火机，他至今保留。
- **主动找出路**: 在节目组受打压后决定离职，但他利用演唱会多部门合作认识的人，挨个打电话问"我能不能去你们那工作"，拿到 ABC 体育部演播运营总监的职位，进入《体育大世界》节目组。

## Mental Models
- 先干起来再说：随便找一份再小的工作开始干，就能认识跟家里人不一样的人、接触新资源；在家呆着什么都没机会。
- 跑腿不丢人：能为大明星买漱口水，"这是非常重要的一项工作"。
- 人脉来自共事，不来自攀附：多工种合作的现场就是认识人的现场。

## Anti-patterns
- 等工作找上门，在家"择业"空耗。
- 把琐碎工作当屈辱，敷衍了事。
- 受到打压就消沉离开，而不是带着积累的关系主动找出路。

## Key Takeaways
1. 起点低不可怕，可怕的是不赋予工作意义。
2. 对小事的投入度，会被关键人物看见（鲁尼正是那场演唱会的负责人）。
3. 离职也要离得主动：带着人脉去打电话，而不是负气消失。
4. 最好的求职方法是先随便找一份工作干起来。

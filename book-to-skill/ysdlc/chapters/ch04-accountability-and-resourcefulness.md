# Chapter 4: 担责与办成不可能

## Core Idea
职场中最重要的两件事，艾格都做对了：犯错被追责时主动站出来，被告知"不可能"时把约束拆开办成。前者让鲁尼对他另眼相看，后者让他证明——"人才就是你给他一个事，他能给你办成"。

## Frameworks Introduced
- **主动担责 (Voluntary Accountability)**: 追责现场第一个站起来的人，最快积累信任资本 (Trust Capital)。
- **拆解约束办成不可能 (Make the Impossible Deal)**: "不行"是约束的表述而非终点；追问约束的边界，设计各方都赢的替代方案。

## Key Concepts
- **撞线镜头漏拍**: 一次世界田径锦标赛，英国选手打破 800 米世界纪录，团队却因工作失误没拍到撞线镜头。鲁尼在会议上大发雷霆拍桌骂"谁负责！谁干的！"全组按惯例沉默——"只要骂人，别说话就行了"。资历最浅、坐在后排的艾格不懂这规矩，站起来说："这个事是我的责任，我负责。"所有人都吓傻了。从此鲁尼对他另眼看待，觉得这孩子能够承担责任、能够主动站出来。
- **平壤乒乓球世锦赛 (1979)**: 筹备已久的报道突遭美国商务部质询——与平壤有商务往来禁令，绝对不能去。换作入职两三年的年轻人大多放弃，艾格却深入了解："如果不收钱还算商务往来吗？"商务部答：不收钱的事我们不管。他再去找平壤谈：不付钱转播，对平壤也是报道。平壤正希望赛事得到全世界报道，谈成了。一件看似不可能的事情竟然办成。
- **人才的定义**: "你给他一个事，他能给你办成，你再给他一件事，他又给你办成了——看起来不能够做到的事，他能够做得到。"

## Mental Models
- 担责是信任资本最快的积累方式：全场沉默时站出来的成本最低、收益最大。
- 禁令是约束条件的集合，不是一堵墙：找到变量（收钱/不收钱），就找到了门。
- 替代方案须让对方也赢：平壤要的是世界报道，不是转播费。

## Anti-patterns
- 遵守"领导骂人时别说话"的潜规则，让责任悬空。
- 接到"不行"就停止，不追问约束的具体边界。
- 把"办成"理解为绕过规则，而非在规则内重构方案。

## Key Takeaways
1. 追责现场主动站起来，是性价比最高的信任投资。
2. 担责展现的是个人责任感，会被关键导师记住并另眼相看。
3. 听到"不可能"先问三个问题：哪条约束？边界在哪？不收钱行不行？
4. 人才的名声靠一件件"办成的事"累积。

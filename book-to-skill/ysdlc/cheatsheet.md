# Cheatsheet: 一生的旅程

## 决策规则
| 当你... | 做什么 |
|---|---|
| 遭遇重大危机/人身伤害事件 | 亲自联系受害者，当天整改；不让公关过滤人性 |
| 原计划失效（赛事取消/资源中断） | 问"我们要讲什么故事"，转向人的故事 |
| 团队犯错、追责现场沉默 | 第一个站起来说"是我的责任" |
| 被告知"不可能/有禁令" | 追问约束边界，找"不收钱"式的替代路径 |
| 高位空降陌生领域 | 承认不懂，压制自尊，多向对方提问 |
| 想进入封闭圈子 | 做出不一样的作品，让人看到 |
| 觉得工作太琐碎没意思 | 自己赋予意义，把小事做到极致 |
| 被头衔和赞美包围 | 守住童真：你还是那个一直以来的自己 |

## 关键概念速查
- 人性化危机领导 = 亲自致电 + 当天整改 + "我也是一个父亲，也是一个爷爷"
- 讲故事优先 = 我们的首要职责是讲故事，而不是播放赛事
- 为了更好不惜一切 = 鲁尼的完美主义；用《寿司之神》示范
- 主动担责 = 全场沉默时站起来说"我负责"→ 信任资本
- 拆解约束 = 不收钱还算商务往来吗？→ 平壤转播谈成
- 外行领导 = 抑制假装内行的冲动，多提问
- 人才 = 把看似办不成的事办成的人

## Tells & Smells
- **Smell**: "这事得先问过公关/法务" → 人性正被流程过滤。
- **Smell**: "比赛取消了，没法播了" → 忘了自己是讲故事的。
- **Smell**: "领导骂人时别说话" → 组织正在流失信任资本。
- **Smell**: "上面说不行，那就算了" → 把约束的表述当成了终点。
- **Smell**: "我得让他们觉得我很懂" → 自尊心占了上风。
- **Smell**: "多请几顿饭就能混进圈子" → 圈子靠做事进，不靠饭局进。
- **Tell**: 追责现场有人第一个站起来 → 这个人会被另眼相看。
- **Tell**: 危机当天就启动整改 → 人性化领导在起作用。

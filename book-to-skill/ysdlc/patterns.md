# Patterns

## Pattern 1: 危机人性化响应 (Human-First Crisis Response)
**When to use**: 发生重大危机，尤其涉及人身伤害、需要你表态时。

**How**:
1. 第一时间确认事实与受害者处境。
2. 决策者亲自联系受害者/家属，不让公关顾问过滤。
3. 以"人"的身份表达（"我也是一个父亲，也是一个爷爷"），不做免责式表态。
4. 当场回应诉求，并在当天启动整改（围起所有湖泊）。
5. 整改落地后再履行公开职责。

## Pattern 2: 讲故事重构 (Story-First Reframing)
**When to use**: 原计划失效（赛事取消、资源中断）或内容同质化时。

**How**:
1. 回到任务本质：我们的首要职责是讲故事，不是传递信号。
2. 盘点"人"的素材：运动员、当事人、幕后。
3. 批量挖掘故事并拍摄呈现，替代原计划内容。
4. 用核心指标验证（卡尔加里收视率不降反升创新高）。

## Pattern 3: 追责现场主动担责 (Volunteer for Accountability)
**When to use**: 团队失误、上级追责、全场沉默时。

**How**:
1. 定位失误中与自己/自己团队相关的环节。
2. 第一个站起来，明确说"这个事是我的责任，我负责"。
3. 不辩解，聚焦补救。
4. 事后用改进兑现，让"另眼相看"落地为信任资本。

## Pattern 4: 拆解约束办成不可能 (Unpack the Constraint)
**When to use**: 被告知"不可能""违规""有禁令"时。

**How**:
1. 不停止，深入了解：具体哪条约束？边界在哪里？
2. 找出约束的变量（付钱/不收钱）。
3. 设计约束内各方仍有收益的替代方案（不收钱转播，平壤获得世界报道）。
4. 与对方谈成，把"办不成的事"办成。

## Pattern 5: 外行高位入场 (Outsider Entry Playbook)
**When to use**: 以高位外行身份空降陌生领域时。

**How**:
1. 公开承认格格不入，不假装内行——不让自尊心占上风。
2. 把会面变成提问式学习，而非展示自己。
3. 快速学习、快速认识所有人，建立关键人物地图。
4. 少数关键拍板依据"确定性差异"（保证跟别的不一样），而非掌握全部细节。

## Pattern 6: 用做事进入圈子 (Earn Entry by Doing)
**When to use**: 想进入一个看似封闭的圈子时。

**How**:
1. 不请客、不送礼、不混饭局。
2. 做出一部"不一样"的作品（《双峰镇》），让圈内人看到。
3. 让成功者主动找上门（斯皮尔伯格、卢卡斯）。
4. 容忍个别失败（《警察摇滚》），不因此停止拍板。

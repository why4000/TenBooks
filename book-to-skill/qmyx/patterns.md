# Patterns

## Pattern 1: 英雄之旅映射 (Hero's Journey Mapping)
**When to use**: 分析叙事结构（故事、电影、个人历程、创业）。

**How**:
1. 识别故事中的"英雄"。
2. 映射四阶段：启程→启蒙→考验→归来。
3. 标注每个阶段的关键事件。
4. 识别缺失或薄弱的阶段。

**Trade-offs**: 不是所有故事都完美契合；它是分析工具，不是模板。

## Pattern 2: 召唤识别 (Call Recognition)
**When to use**: 感到生活"不对劲"但不确定是否要改变时。

**How**:
1. 识别打破平衡的信号（召唤）。
2. 检查自己是否在"拒绝召唤"。
3. 理解拒绝召唤的代价（困境加深）。
4. 寻找"超自然援助"（导师、资源）。

## Pattern 3: 鲸鱼之腹式转变 (Belly-of-the-Whale Transformation)
**When to use**: 经历重大转变时。

**How**:
1. 认识到转变需要先"放弃旧自我"。
2. 允许自己经历"黑暗期"（鲸鱼之腹）。
3. 在黑暗中重新整合。
4. 以新身份"重生"。

**Trade-offs**: 这个过程不舒服，不能跳过。

## Pattern 4: 终极恩赐定位 (Ultimate Boon Identification)
**When to use**: 在考验中迷失方向时。

**How**:
1. 问：这段旅程的"终极恩赐"是什么？
2. 恩赐是为了带回社群，不是个人占有。
3. 确认当前考验与恩赐的关系。
4. 聚焦恩赐，不被诱惑带偏。

## Pattern 5: 归来整合 (Return Integration)
**When to use**: 获得新认知后需要回归日常时。

**How**:
1. 认识到归来也是旅程的一部分。
2. 寻找"外界救援"（让他人帮助你整合）。
3. 将新认知转化为日常语言和行动。
4. 成为"两个世界的主宰"。

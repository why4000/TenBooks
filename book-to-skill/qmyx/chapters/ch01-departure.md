# Part 1: 启程 (Departure)

## Core Idea
英雄之旅始于召唤。英雄从日常世界被召唤到冒险中，经历拒绝→接受援助→跨越阈限→象征性死亡（鲸鱼之腹），完成从日常到冒险世界的转变。

## Stages
1. **冒险的召唤**: 某个信号/事件打破日常平衡，召唤英雄踏上旅程。
2. **拒绝召唤**: 英雄因恐惧、责任等拒绝召唤——但拒绝只会让困境加深。
3. **超自然援助**: 导师出现，给予护身符、指引或力量。
4. **跨越第一道阈限**: 英雄越过已知与未知的边界，进入冒险世界。
5. **鲸鱼之腹**: 英雄被未知吞没，经历象征性死亡与重生，与旧身份告别。

## Key Concepts
- **阈限 (Threshold)**: 已知世界与未知世界的边界。
- **阈限守护者**: 考验英雄决心的障碍。

## Mental Models
- 召唤像一封信：你可以不拆，但它不会消失。
- 鲸鱼之腹像种子破土：先在黑暗中分解，才能长出新芽。

## Key Takeaways
1. 召唤不可逃避——拒绝只会延迟。
2. 导师的援助是跨越阈限的关键。
3. 鲸鱼之腹是转变的必经之路——先"死"才能"生"。

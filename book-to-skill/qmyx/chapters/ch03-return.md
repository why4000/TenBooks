# Part 3: 考验与归来 (Trials & Return)

## Core Idea
英雄获得恩赐后必须归来，将恩赐带回社群。但归来同样充满考验——拒绝归来、逃脱、救援、跨越回归阈限，最终成为两个世界的主宰。

## Stages
1. **拒绝归来**: 英雄沉醉于冒险世界的启示，不愿回到日常。
2. **魔法逃脱**: 英雄带着恩赐逃离，被守护者追逐。
3. **外界救援**: 英雄需要外部帮助才能跨越回归阈限。
4. **跨越回归阈限**: 英雄将冒险世界的智慧带入日常世界。
5. **两个世界的主宰**: 英雄能同时驾驭内心世界和外部世界。
6. **自由生活**: 英雄超越恐惧，获得自由。

## Key Concepts
- **回归阈限**: 从冒险世界回到日常世界的边界。
- **两个世界的主宰**: 英雄的终极状态——内心与外部和谐。

## Mental Models
- 归来像留学归国：带着新知识回来，但要让本地人理解。
- 两个世界的主宰像双语者：在两个世界间自如切换。

## Key Takeaways
1. 获得恩赐后必须归来——否则只是逃避。
2. 归来需要外界救援——独自跨越很难。
3. 终极目标是两个世界的主宰，不是逃离任一个。

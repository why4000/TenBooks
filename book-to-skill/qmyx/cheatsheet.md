# Cheatsheet: 千面英雄

## 英雄之旅四阶段
```
启程 → 启蒙 → 考验 → 归来
(出发)  (转化)  (回归)
```

## 阶段速查
| 阶段 | 关键节点 | 核心 |
|---|---|---|
| 启程 | 召唤→拒绝→援助→跨越阈限→鲸鱼之腹 | 从日常到未知 |
| 启蒙 | 考验之路→女神→诱惑→赎罪→神化→恩赐 | 转化与获得 |
| 归来 | 拒绝归来→逃脱→救援→回归阈限→两世界主宰 | 带回恩赐 |

## 决策规则
| 当你感到... | 你可能在... |
|---|---|
| 生活不对劲但想维持现状 | 拒绝召唤 |
| 进入全新领域感到迷失 | 鲸鱼之腹 |
| 一连串困难和试炼 | 考验之路 |
| 获得新认知但不想回到日常 | 拒绝归来 |
| 在两个世界间感到撕裂 | 跨越回归阈限 |

## 原型速查
| 原型 | 功能 |
|---|---|
| 英雄 | 踏上旅程 |
| 导师 | 给予援助 |
| 阈限守护者 | 考验决心 |
| 女神 | 滋养与爱 |
| 女妖 | 诱惑 |
| 父亲 | 权威与和解 |

## Tells & Smells
- **Smell**: "等准备好再开始" → 拒绝召唤。
- **Smell**: 获得新知后不想与人分享 → 拒绝归来。
- **Smell**: 把英雄之旅当成功学公式 → 误解了它的心理学本质。
- **Tell**: 经历了一段黑暗期后感觉"变了一个人" → 鲸鱼之腹式转化。

# Patterns

## Pattern 1: 基础拆除 (Foundation Demolition)
**When to use**: 一大堆信念彼此支撑，逐条核查既不可能也无意义。

**How**:
1. 列出这些信念共同依赖的原则（通常是知觉或权威的可靠性）。
2. 只针对原则构造最强的反例（梦境、欺骗者、极端情境）。
3. 一旦原则失守，宣布整座大厦暂时停用，不做逐条清算。
4. 记录哪些信念随基础一同倒下，哪些仍站着。

## Pattern 2: 阿基米德点搜索 (Archimedean Point Search)
**When to use**: 需要在全面怀疑之后重新起步，找到第一块落脚石。

**How**:
1. 假定一切被怀疑对象都不存在。
2. 找出"做这个假定"这一行为本身所预设的东西。
3. 检验：能否在不自相矛盾的前提下设想它不存在？不能，则为基点。
4. 只承认由这个基点直接蕴含的内容，暂不扩张。

## Pattern 3: 清楚分明检验 (Clarity Test)
**When to use**: 判断一个观念、定义或命题能否作为推理前提。

**How**:
1. 把对象单独置于注意力的中心，排除情绪、习惯与他人意见。
2. 问"清楚"：它是否完整地呈现在当下，而非靠记忆或联想补足？
3. 问"分明"：它的边界是否锐利，能否与邻近概念一刀切开？
4. 若二者缺一，标记为"待定"，不得用于肯定或否定。
5. 复核：我此刻是在领会，还是在相信？

## Pattern 4: 因果溯源 (Causal Ascent)
**When to use**: 追问"我持有的这个观念/标准/能力从何而来"，或判断某结果是否可能出自某原因。

**How**:
1. 把对象拆成"表象内容"与"现实根据"两层。
2. 评估表象内容所含的完满性等级（实体 > 样态；无限 > 有限）。
3. 检查候选原因：它是否至少以同等或更高的方式含有该完满性？
4. 逐级上溯，直到找到一个自身能承担该完满性的原因。

## Pattern 5: 错误归因 (Error Attribution)
**When to use**: 复盘一次判断失误，要分清"材料不足"与"程序违规"。

**How**:
1. 拆开判断的两个部件：领会（理智）与裁决（意志）。
2. 检查理智：当时是否真的清楚分明地领受了全部相关内容？
3. 检查意志：是否在未清楚之处仍然下了肯定或否定？
4. 若属后者，定性为"意志越界"，补救是悬置判断而非增加信息。
5. 记录触发越界的因素：时间压力、习惯、情绪、群体意见。

## Pattern 6: 可分离性检验 (Separability Test)
**When to use**: 判定两个东西是"同一物的两个面向"还是"两个可分开的实体"。

**How**:
1. 分别写出二者的完整定义，检查是否互相包含。
2. 尝试在不牵涉对方的情况下清楚分明地领会其一。
3. 检查这种领会是"完整认识"还是"片面抽象"——后者不足以支撑实在区别。
4. 若可分离，再问：这种分离是认识上的、能力上的，还是存在上的？
5. 补一句反向检验：我是否同时经验到二者不可分割地统一？

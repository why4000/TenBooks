# Cheatsheet: 第一哲学沉思集

## 六沉思速查
| # | 沉思 | 一句话 | 关键动作 |
|---|------|--------|----------|
| 1 | 论可以引起怀疑的事物 | 拆地基而非拆房子 | 悬置一切可怀疑者 |
| 2 | 论精神的本性 | 我思故我在；蜡由理智认识 | 找不可退的基点 |
| 3 | 论上帝及其存在 | 无限观念必有无限原因 | 按客观实在性上溯 |
| 4 | 论真理和错误 | 意志宽于理智，故有错 | 未清楚前不下判断 |
| 5 | 论物质性东西的本质 | 本质永恒；存在属上帝本质 | 分清本质与存在 |
| 6 | 论物质性东西的存在 | 物体存在；身心实在区别且统一 | 用上帝非骗子收口 |

## 决策规则
| 当你... | 做什么 |
|---|---|
| 一堆信念来源可疑、互相支撑 | 找共用原则，抽掉它，不逐条驳 |
| 需要绝对可靠的起点 | 假定一切为假，找"假定"本身预设的东西 |
| 判断某观念能否当前提 | 过"清楚 + 分明"双检，缺一即待定 |
| 感觉"显然为真"但说不出理由 | 分清自然的光明与自然的倾向 |
| 追问某观念从哪来 | 按客观实在性等级做因果上溯 |
| 复盘一次错误 | 先查理智亮度，再查意志是否越界 |
| 被要求在信息不足时表态 | 悬置判断——这是可实行的第二种不犯错法 |
| 从"定义"直接推出"存在" | 停：只有"存在属于本质"者才可跨越 |
| 判断两物是否可分开 | 做可分离性检验，并追问是完整认识还是片面抽象 |
| 在"身心是一是二"间摇摆 | 两者都要：实在区别 + 组成统一 |

## 关键概念速查
- 我思故我在 = 每次说出/想到时重新为真，不是存档结论
- 清楚 = 当下呈现；分明 = 边界锐利
- 客观实在性 = 观念中表象的完满性；形式实在性 = 原因中现实的完满性
- 无中不能生有 = 结果中的完满性必先在原因中
- 错误 = 意志扩展到理智未照亮处，而非"能力的缺陷"
- 无所谓 = 最低程度的自由，不是自由的高峰
- 实在区别 = 可分别清楚领会 + 上帝全能可分置
- 自然 = 上帝建立的身心总和之秩序，不是价值规范

## Tells & Smells
- **Tell**: 能说出"我为什么确信"而不只是"我很确信" → 已过清楚分明检验。
- **Tell**: 敢于在关键处说"我暂不判断" → 意志已被正确使用。
- **Tell**: 承认"我能领会 X 而不牵涉 Y" → 可分离性论证的前提成立（还须补"完整认识"）。
- **Smell**: "这不可能错，大家都这么看" → 习惯与众人意见，不是明见性。
- **Smell**: "证据不够，但我先下结论" → 典型的意志越界。
- **Smell**: "既然定义如此，它就存在" → 把本质兑换成存在。
- **Smell**: "我很想相信，所以它是自然告诉我的" → 把倾向当光明。
- **Smell**: "感觉骗过我，所以感觉全不可信" → 从个别失误跳到全盘否定，正是第一沉思要避免的过度。

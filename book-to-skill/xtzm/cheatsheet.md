# Cheatsheet: 系统之美

## 系统三要素优先级
要素 < 连接 < 功能/目标
（改变目标影响最大，改变要素影响最小）

## 反馈回路速查
| 类型 | 行为 | 比喻 |
|---|---|---|
| 调节回路 | 趋向目标、稳定 | 恒温器 |
| 增强回路 | 增长或崩溃 | 滚雪球/复利 |
| +延迟 | 振荡 | 淋浴调温 |

## 8大基模速查
| 基模 | 信号 | 对策 |
|---|---|---|
| 政策阻力 | 各方努力互相抵消 | 找共赢总目标 |
| 公地悲剧 | 共享资源枯竭 | 教育/私有化/管制 |
| 目标侵蚀 | 标准逐渐降低 | 用历史最佳作基准 |
| 竞争升级 | 双方加码失控 | 谈判/单方让步 |
| 富者愈富 | 强者恒强 | 反垄断/平衡起跑线 |
| 转嫁负担 | 依赖症状解 | 聚焦根本解 |
| 规避规则 | 上有政策下有对策 | 重新设计规则 |
| 目标错位 | 指标≠目标 | 明确真实目标 |

## 12大杠杆点（弱→强）
12.数字 → 11.缓冲器 → 10.存量-流量结构 → 9.时间延迟 → 8.调节回路 → 7.增强回路 → 6.信息流 → 5.规则 → 4.自组织 → 3.目标 → 2.范式 → 1.超越范式

## 决策规则
| 当你看到... | 做什么 |
|---|---|
| 问题反复出现 | 找基模，用根本解 |
| 调参数无效 | 往更高杠杆点移动 |
| 系统振荡 | 检查延迟 |
| 个体最优整体差 | 有限理性，改信息流/规则 |
| 增长停滞 | 找当前限制因素 |

## Tells & Smells
- **Smell**: "只要再调一下参数就好" → 可能在最弱杠杆点上白费力气。
- **Smell**: "我们一直这么做" → 范式未被审视。
- **Smell**: 指标越来越好但实际变差 → 目标错位。
- **Tell**: 去掉某个症状解后问题反弹 → 转嫁负担成瘾。

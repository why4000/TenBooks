# Chapter 1: 系统之基础

## Core Idea
系统由要素、连接、功能/目标三要素构成。系统行为的动态性来自存量-流量结构和反馈回路（调节回路+增强回路）。

## Frameworks Introduced
- **系统三要素**: 要素（组成部分）、连接（要素间关系）、功能/目标（系统目的）。连接和目标比要素更重要。
- **存量 (Stock)**: 系统中累积的量，可观察、变化慢。
- **流量 (Flow)**: 改变存量的流入流出，变化快。
- **调节回路 (Balancing Loop)**: 趋向目标、稳定系统（恒温器）。
- **增强回路 (Reinforcing Loop)**: 放大变化、增长或崩溃（复利）。

## Key Concepts
- **总体大于部分之和**: 系统行为来自结构，不是要素之和。
- **反馈**: 系统输出影响输入的机制。

## Mental Models
- 存量像浴缸里的水，流量是水龙头和排水口。
- 调节回路像恒温器，增强回路像滚雪球。

## Anti-patterns
- 试图直接改变存量（如直接命令库存减少）——只能通过流量改变。
- 只关注要素，忽视连接和目标。

## Key Takeaways
1. 系统行为由结构（连接+目标）决定，不由要素决定。
2. 存量-流量结构决定动态行为。
3. 所有系统行为都来自调节回路和增强回路的组合。

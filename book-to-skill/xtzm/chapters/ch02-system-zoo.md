# Chapter 2: 系统大观园

## Core Idea
通过单存量系统和双存量系统的案例，展示不同的存量-流量-反馈结构如何产生不同的行为模式。

## Frameworks Introduced
- **单存量系统**: 一个存量+一个或两个反馈回路。
  - 一个调节回路+延迟 → 振荡（如库存管理）
  - 一个增强回路 → 指数增长或崩溃
- **双存量系统**: 两个相互关联的存量。
  - 可再生资源系统（如渔业）：资源存量+经济存量
  - 不可再生资源系统：资源有限，经济增长后必然衰退

## Key Concepts
- **振荡 (Oscillation)**: 延迟导致系统在目标附近上下波动。
- **指数增长**: 增强回路的典型行为。
- **过度冲销 (Overshoot)**: 系统超过承载能力后崩溃。

## Mental Models
- 可再生资源像渔业：捕太多→鱼减少→捕更少；捕太少→经济受损。
- 不可再生资源像石油：越用越少，最终枯竭。

## Key Takeaways
1. 不同的反馈结构产生不同的行为模式。
2. 延迟是振荡的主要原因。
3. 可再生与不可再生资源系统行为根本不同。

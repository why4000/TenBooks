# Chapter 4: 系统之奇——系统的6大障碍

## Core Idea
系统行为常让人意外，因为我们的思维有6大障碍：被表象迷惑、线性思维、边界划定、忽视限制因素、忽视时间延迟、有限理性。

## Frameworks Introduced
1. **别被表象所迷惑**: 事件是表象，行为模式是中层，系统结构是根源。
2. **非线性世界不用线性思维**: 现实多是非线性的，线性外推常出错。
3. **恰当地划定边界**: 系统没有真正的边界，边界是人为划定的。
4. **看清各种限制因素**: 任何增长都受某个因素限制，识别当前限制因素。
5. **无所不在的时间延迟**: 行动与结果之间有延迟，导致反应过度或不足。
6. **有限理性**: 每个人基于局部信息做最优决策，但整体可能非最优。

## Key Concepts
- **事件-行为-结构 (E-B-S)**: 三层分析框架。
- **限制因素**: 增长的瓶颈，随阶段变化。

## Mental Models
- 像驾驶一辆有延迟的汽车：转向后车要过一会才转，容易过度修正。
- 有限理性像盲人摸象：每个人看到局部，整体可能非最优。

## Key Takeaways
1. 看结构，不看事件。
2. 现实是非线性的。
3. 边界是人为的。
4. 找到当前限制因素。
5. 预期并处理延迟。
6. 理解有限理性，设计系统让个体最优=整体最优。

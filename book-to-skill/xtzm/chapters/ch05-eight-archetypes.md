# Chapter 5: 系统之危与机——系统的8大陷阱与对策

## Core Idea
8种常见的系统基模（陷阱），每种都有对应的对策。识别基模是找到根本解的关键。

## Frameworks Introduced
1. **政策阻力 (Policy Resistance)**: 各方努力抵消彼此。对策：放弃压制，寻找各方共赢的总目标。
2. **公地悲剧 (Tragedy of the Commons)**: 共享资源被过度使用。对策：教育劝诫、私有化、管制（三种方式）。
3. **目标侵蚀 (Goal Erosion)**: 目标随坏结果降低。对策：保持绝对标准，用历史最佳作基准。
4. **竞争升级 (Escalation)**: 双方互相加码。对策：谈判、单方让步、引入调节回路。
5. **富者愈富 (Success to the Successful)**: 优势者获更多优势。对策：反垄断、多元化、平衡起跑线。
6. **转嫁负担 (Shifting the Burden)**: 用症状解替代根本解，导致依赖。对策：聚焦根本解，减少症状解。
7. **规避规则 (Rule Beating)**: 绕过规则。对策：重新设计规则，使其指向真正目标。
8. **目标错位 (Wrong Goal)**: 用错误指标衡量目标。对策：明确真实目标，选用合适指标。

## Key Concepts
- **症状解 vs 根本解**: 症状解缓解表象，根本解消除原因。
- **基模 (Archetype)**: 常见的反馈结构模式。

## Mental Models
- 转嫁负担像吃止痛药：缓解疼痛但不治病，越吃越依赖。
- 目标侵蚀像煮青蛙：水温慢慢升，青蛙慢慢适应，最后被煮死。

## Key Takeaways
1. 识别基模→找到根本解。
2. 症状解会成瘾，慎用。
3. 公地悲剧需要制度设计。
4. 目标和指标必须一致。

# Patterns

## Pattern 1: 存量-流量分析 (Stock-Flow Analysis)
**When to use**: 理解系统的动态行为。

**How**:
1. 识别存量（累积的量）。
2. 识别流入和流出（流量）。
3. 分析流量如何受存量影响（反馈回路）。
4. 预测行为模式（增长、振荡、崩溃）。

**Trade-offs**: 需要准确识别存量和流量，初学者易混淆。

## Pattern 2: 反馈回路识别 (Feedback Loop Identification)
**When to use**: 分析系统行为的原因。

**How**:
1. 问：存量的变化如何反过来影响流入/流出？
2. 识别调节回路（趋向目标）。
3. 识别增强回路（放大变化）。
4. 检查延迟。

## Pattern 3: 系统基模匹配 (Archetype Matching)
**When to use**: 遇到反复出现的问题模式。

**How**:
1. 描述问题行为模式。
2. 对照8大基模，找到最匹配的。
3. 应用该基模的对策。

**Trade-offs**: 不要削足适履；基模是启发，不是教条。

## Pattern 4: 杠杆点定位 (Leverage Point Location)
**When to use**: 寻找最有效的干预点。

**How**:
1. 从最弱杠杆点（数字）开始检查。
2. 逐步向上：缓冲器→结构→延迟→回路→信息流→规则→自组织→目标→范式。
3. 在能改变的最高杠杆点上行动。

**Trade-offs**: 高层杠杆点难改变但效应大。

## Pattern 5: 症状解 vs 根本解 (Symptomatic vs Fundamental Solution)
**When to use**: 问题反复出现，治标不治本。

**How**:
1. 识别当前的"症状解"。
2. 问：症状解是否在掩盖根本原因？
3. 找到并实施根本解。
4. 逐步减少症状解。

## Pattern 6: 事件-行为-结构分析 (E-B-S Analysis)
**When to use**: 不被表象迷惑。

**How**:
1. 事件（发生了什么？）→ 表象
2. 行为模式（趋势如何？）→ 中层
3. 系统结构（什么反馈结构导致？）→ 根源

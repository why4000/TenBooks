# Chapter 5: 共同进化

## Core Idea
进化不是单向的，而是物种间相互塑造的过程。捕食者与猎物、宿主与寄生者、技术与自然，互为选择压力，共同进化。

## Frameworks Introduced
- **共同进化 (Coevolution)**: 两个或多个物种/系统互为选择压力，彼此塑造。
- **军备竞赛 (Arms Race)**: 捕食者变强→猎物变强→捕食者更强...正反馈循环。
- **共生 (Symbiosis)**: 不同物种相互受益，共同生存。

## Key Concepts
- **相互选择压力**: A的变化改变B的适应度，B的变化改变A的适应度。
- **红皇后效应**: 必须不断进化才能留在原地（"你必须拼命跑，才能留在原地"）。

## Mental Models
- 共同进化像跳舞：双方都在移动，都在回应对方的移动。
- 红皇后像跑步机：越跑越快，只是为了不被淘汰。

## Key Takeaways
1. 进化是相互的，不是单向的。
2. 系统间的关系塑造了系统的形态。
3. 共同进化可以是军备竞赛，也可以是共生。

# Cheatsheet: 失控

## 造物九律速查
| # | 法则 | 核心 |
|---|------|------|
| 1 | 分布式存在 | 不要集中 |
| 2 | 自下而上的控制 | 控制从底层涌现 |
| 3 | 递增收益 | 正反馈 |
| 4 | 模块化生长 | 先模块后组合 |
| 5 | 边界最大化 | 边界处创新最多 |
| 6 | 鼓励犯错误 | 错误是进化素材 |
| 7 | 不求最优化，但求多目标 | 多样>最优 |
| 8 | 谋求持久的不均衡态 | 均衡=死亡 |
| 9 | 变自生变 | 改变方式也要进化 |

## 决策规则
| 当你... | 做什么 |
|---|---|
| 试图完全控制复杂系统 | 放手，用反馈替代指令 |
| 解空间太大无法穷举 | 用进化搜索 |
| 系统反应迟钝 | 检查是否过度集中 |
| 追求"最优解" | 改为追求多目标适应 |
| 害怕错误 | 把错误当进化素材 |

## 关键概念速查
- 涌现 = 整体>部分之和
- 蜂群思维 = 无中心的群体智能
- 共同进化 = 相互塑造
- 红皇后 = 不断进化才能留在原地
- 必要多样性定律 = 控制器≥被控系统

## Tells & Smells
- **Smell**: "我们需要一个中央控制系统" → 对复杂系统注定失败。
- **Smell**: "消灭所有错误" → 消灭了进化的素材。
- **Smell**: "达到最优就好" → 最优是陷阱，多样才是力量。
- **Tell**: 系统在边界处最有活力 → 边界最大化在起作用。

# Patterns

## Pattern 1: 熵账本分析 (Entropy Accounting)
**When to use**: 判断一个系统、组织或文明宣称的"进步"是否可持续。

**How**:
1. 列出该系统维持秩序所摄取的能量、物质与信息。
2. 标出它把熵排到哪里（废弃物、外部成本、被消耗的资源）。
3. 区分"动用本金"与"提升效率"：前者不可持续，后者才可能持续。
4. 检查进步是否制造了不可逆的新限制（环境改造、路径依赖）。
5. 给出结论：当前秩序能维持多久，取决于哪一项输入先耗尽。

## Pattern 2: 反馈回路审计 (Feedback Loop Audit)
**When to use**: 命令下了但执行走样，或管理层层失真。

**How**:
1. 画出感受器—决策器—效应器—回传路径。
2. 检查回传是否测量"实际演绩"而非"意图"。
3. 找出转导环节中信息可能永久逸失的位置。
4. 区分简单反馈（是否达成）与策略反馈（总计划是否成功）。
5. 补上缺失的回传，或降低回传延迟与失真。

## Pattern 3: 定型/学习诊断 (Rigid-Learning Diagnosis)
**When to use**: 组织对环境变化反应迟钝，或岗位被固定为重复职能。

**How**:
1. 列出关键行为模式，判断每条是"结构锁定"还是"可依经验修改"。
2. 检查是否存在修改策略的权限与时间；没有权限，学习无从发生。
3. 识别"紧身衣"式制度：职能永久固定、只训练动作不训练策略。
4. 估算学习期投入是否与未来不确定性匹配。
5. 给出解冻方案：下放策略修改权，建立策略层反馈。

## Pattern 4: 消息化建模 (Model as Message)
**When to use**: 分析远程协作、数字化复制、身份延续或"物质 vs 信息"的替代。

**How**:
1. 把对象拆成"质料"与"模式"两部分。
2. 判断维持其同一性的是哪一种：若为模式，则原则上可消息化。
3. 列出模式传输所需的感觉通道、存贮与再体现条件。
4. 评估哪些环节必须保留物质运输，哪些可以改为信息运输。
5. 检查接收端是否有足够的组织能力把消息重新体现为可用模式。

## Pattern 5: 控制论社会政策评估 (Cybernetic Policy Review)
**When to use**: 评估保密、专利、媒体管制、信息公开等通信政策。

**How**:
1. 识别政策控制的是哪一层通信：信源、信道、信码、语义还是执行。
2. 区分自然噪声与有意堵塞；后者需要不同的对抗策略。
3. 检查政策是否提高了通信成本、压缩了异质声音。
4. 检查是否制造"伪通信"激励（为声望而非为内容而发声）。
5. 评估对法律可预期性、科学诚实与公共决策回传的影响。

## Pattern 6: 自动化过渡规划 (Automation Transition Planning)
**When to use**: 引入自动化、AI 或任何替代低层判断劳动的技术。

**How**:
1. 按"替代层级"盘点：这项技术替代体力、重复脑力，还是判断本身？
2. 用"奴隶劳动基准"估算同类劳动的价格与就业冲击。
3. 识别不适用的边界：小规模、多品种、高变化、高基本投资场景。
4. 把过渡期单独规划：再培训、工时缩短、分配机制、社会安全网。
5. 设定采用节奏与公共利益条件，避免"眼前有利即采用"。

## Pattern 7: 信息流通性审计 (Information Flow Audit)
**When to use**: 设计或评估保密、专利、版权、知识资产管理政策。

**How**:
1. 判断对象是"守恒型资产"（金子、电能）还是"非守恒型资产"（信息、秩序）。
2. 对非守恒资产，列出其贬值途径：传播、熟悉、技术换代、竞购力下降。
3. 计算保密的时间账：保护强度 × 解密延迟，两者相乘才是真实成本。
4. 检查"储藏"是否替代了"流通"：成果是否被标密封存而非持续使用。
5. 检查分隔是否造成重复发现：同一成果是否在不同隔间被重复发明。
6. 给出结论：唯一可持续的安全形式是持续流通与更新。

## Pattern 8: 感官替代设计 (Sensory Substitution Design)
**When to use**: 为受损感官设计替代通道，或把信息迁移到带宽更低的信道。

**How**:
1. 把任务拆成三阶段：物理信号 → 生理编码 → 语义理解；确认受损的是哪一段。
2. 不搬运原始信号，先提取"理解语义所需的那一部分"（如言语的少数频带包络）。
3. 选择替代信道，并核实其单位时间信息容量是否够用（触觉低于听觉，须先压缩）。
4. 把原本由中枢完成的过滤功能外置，做成"人造外在皮质"。
5. 设计训练过程：替代通道的语义映射必须靠学习建立，而非天生。
6. 保留原有通道的反馈：让使用者能持续自我监督与自我批判。

## Pattern 9: 通信博弈诊断 (Communication Game Diagnosis)
**When to use**: 判断通信故障是自然噪声、有意堵塞，还是我们把混乱误读成了阴谋。

**How**:
1. 先分清故障来源：自然噪声（无意）、人为堵塞（有意）、自身能力不足（内部）。
2. 若为人为堵塞，按博弈框架分析：对方是否会随我方技术升级而改变策略。
3. 检查是否落入摩尼教式投射：是否把对等的、会出招的恶意，安到了不做策略调整的自然或对手身上。
4. 检查组织是否以"绝对效忠"替代"坦白为怀"，从而把科研变成反谍。
5. 评估防守成本：用于防幻影的力量，本可用于理解世界。
6. 给出处置：对自然用诚实提问，对堵塞用博弈对策，对自身用能力建设。

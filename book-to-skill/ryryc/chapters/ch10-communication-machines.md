# 第十章：几种通信机器及其未来

## Core Idea
当个体人被用作基本成员来编织成一个社会时，如果他们不能恰如其分地作为负责任的人、而只是作为齿轮、杠杆和连杆，那么即使原料是血是肉，**实际上和金属并无什么区别**。本章考察三类通信机器：为理论目的制造的向性机器、补偿感官与器官缺陷的医疗机器，以及具有不祥可能性的弈棋机与"国家管理机器"。贯穿始终的判据是：**除非问题提得正确，我们决不会得到正确的答案**。

## Frameworks Introduced

### 目的震颤与姿势反馈 (Intention Tremor and Postural Feedback)
- 随意活动本质上是反馈性质的（维纳与罗森勃吕特、毕格罗 1943 年的论文）：在人的随意活动中寻找负载过度时反馈失灵的特征。
- **目的震颤**：患者伸手取水杯时手摆动得愈来愈厉害，以致拿不到杯子；起因是小脑受损、主反馈过载。
- **帕金森症候群**：休息时震颤，企图完成确定目的时反而平息；源于第二级反馈（姿势反馈）过载，其方向与随意反馈相反，因此目的的存在会抑制姿势反馈的振荡。
- **"飞蛾"与"臭虫"**：辛格莱顿制造的小推车，一对光电管 + 电桥 + 可调放大器 + 伺服电动机，实现趋光或避光。放大器增益过大时，它以振荡方式觅光或避光，酷似目的震颤；舵定位的第二级反馈过载时，在无光（无目的）时出现第二类震颤，酷似帕金森症候群。
- 瓦尔特（Bristol 布登神经病学研究所）造出目的可变的同类机器，并指出"除负反馈外的种种特性都考虑进去了"。
- 这类机器并非纯粹玩具：美军医疗队用"飞蛾"的照片与实际神经震颤病例照片比较，认为有助于训练神经病学军医。

### 感官替代 (Sensory Substitution)
- 语言可分三个阶段、两个中介：声学符号（空气振动）→ 语音学（内耳与神经系统）→ 语义学（意义经验）。
- 聋人缺第二阶段，但第二阶段可绕过听觉器官**用触觉器官替代**；新旧阶段的过渡由人造系统完成。
- 依据是自动语音合成器 (vocoder)：把言语划分为不超过五个频带，检波取出包络，再用包络调制各频带内的任意声音并叠加，仍可辨识原言语乃至说话人——但可传送的信息量已缩到原来的十分之一到百分之一。
- 电话只模拟耳朵，不模拟脑中理解言语的器官；言语的有效信息远小于耳朵的最大编码能力（10000 Hz、80 dB 是上限，电话只有 3000 Hz 以下、5–10 dB）。
- 做法：类似 vocoder 分出五个频带，调制到皮肤可感知的振动，分别送往一只手的拇指与其余四指。**在信息进入触觉接收器之前，先用过滤器代替大脑皮质的那部分功能**，即把脑皮质的部分功能转嫁给"人造的外在皮质"。
- 同类项目：盲人助用器（视觉模式转听觉信号、逐页阅读）、盲人导航、人造肺（由病人残存肺肌的电/机械信号驱动呼吸马达，使"铁肺"从监狱变成练习工具）。

### 弈棋机与有限前瞻 (Chess Machine and Bounded Lookahead)
- 完美棋机无望：棋步组合大体按几何级数增长，要在合理时间内算完一盘五十步的棋是机器办不到的。
- 可行目标：保证每着之后有限几步（如两步）内最优，从而按某种估算方法使自身处于最有利位置。
- 香农的改进：估算包含棋局控制、相互防护、子力、将军与将死；若两步后因将军、失子或"两头将"而不稳定，就再动一子或两子直到稳定；并可加入机遇，避免纯系统化走法的僵化。
- 可学习棋机：记录过往每一盘棋，从棋局中找出诀窍；对手水平决定机器才能——"一匹马也会被骑坏的，如果让拙劣的骑手去糟蹋它的话"。
- **选择性 vs 限制性决定 (Selective vs Restrictive)**：制造机器时，要么给它某类行为的统计倾向而不排斥其他可能（选择性），要么把某些行为特性严格不变地决定下来（限制性）。若把棋规作为"限制"而非可学倾向，机器就只能下棋；若不把棋规作为限制而机器又能学习，它会不知不觉变成执行完全不同任务的机器。

### 国家管理机器 (Machine à Gouverner)
- 杜巴勒（多明我会修士，1948 年评论《控制论》）设想：机器搜集生产、市场、舆论等信息，按统计规律推断事态最可几的发展，乃至统辖政治裁决。
- 人事过程只能确定可几值，不能像数字计算那样确定；因此这类机器须有概率论思想而非决定论思想，任务更复杂但并非不可能。
- 两个稳定性条件：其一，广大博弈者十分愚蠢无知、受一位精明博弈者愚弄（甚至被设计出麻痹群众意识的方法）；其二，有足够善意允许某人把决定交给少数具任意特权的博弈者。除此以外，人事的机械操作可能根本破产。
- **真正的危险不是机器自主，而是机器可被某人或某伙人利用来增强对其余人的控制**；或者政治领导人不用机器，却用"好像由机器制定出来"的狭隘政治技术控制人民。
- 机器的最大弱点，正是我们尚不至于被它统治的原因：它算不出表征人事变化幅度甚大的概率性。用机器统治人类，预设社会已处在熵增的最后阶段、统计偏差等于零。

### 博弈论作为通信理论 (Game Theory as Communication Theory)
- 冯·诺伊曼与摩根斯坦的《博弈论》给人深刻印象，华盛顿亦然；香农指出弈棋机可作为"估计军事情势、决定最优行动"的机器的前身。
- 现有博弈论多假定双方有无限才干，限制只来自手上的牌或棋盘局势；有证据表明俄国方面补充了博弈者的心理限制，特别是其作为博弈组成部分的疲劳性。
- 结论：世界矛盾的双方本质上都在使用某种"国家管理机器"，它虽非独立制定策略的机器，却是适应那群"像机器般的人"紧急需要的机械技术。

## Key Concepts
- **向性 (Tropism)** — 机器对单一固定目的（趋光/避光）的反应方式，是随意反馈的模拟。
- **目的震颤 (Intention Tremor)** — 主反馈过载导致的、随主动取物而加剧的振荡。
- **姿势反馈 (Postural Feedback)** — 维持关节适度强直的第二级反馈，过载即帕金森式震颤。
- **感官替代 (Sensory Substitution)** — 用触觉等较低带宽信道替代听觉，并预先过滤以匹配语义。
- **vocoder (自动语音合成器)** — 用少量频带包络重建可懂言语，是信息量度量的经典工作。
- **选择性/限制性约束 (Selective / Restrictive Constraints)** — 学习机设计中"可塑倾向"与"硬性锁定"的区分。
- **国家管理机器 (Machine à Gouverner)** — 以统计规律管理社会事务的假想中央决策机器。
- **有限前瞻 (Bounded Lookahead)** — 在组合爆炸下只保证近几步最优的决策策略。

## Mental Models
- **造出来才算懂**：能复现现象的模型，比口头理论更能检验关于反馈的假设。
- **换信道不换语义**：感官替代的关键不是把声音原样搬给皮肤，而是先把信息压缩成语义所需的那一部分。
- **棋机像有限前瞻的决策者**：不追求全局最优，只求在可计算范围内稳健。
- **国家管理机器像一面镜子**：它照出的不是机器的野心，而是使用者的意图与社会的熵水平。

## Anti-patterns
- **追求完美全局最优**：无视组合爆炸，把不可计算的目标当作设计目标。
- **把人当齿轮却期待人的判断**：用血肉做金属零件，然后抱怨系统没有适应性。
- **把危险归咎于机器自主**：忽略"被谁使用、为谁使用"这一真正变量。
- **盲目提高反馈增益**：增益过载正是目的震颤与帕金森式振荡的成因。
- **用机器统治人类**：这预设社会已进入统计偏差趋零的熵增末期。

## Key Takeaways
1. 人的随意活动是反馈活动；反馈过载会以震颤形式暴露出来，可造机器复现并用于训练。
2. 感官替代的可行性取决于先把信息压缩到语义所需的最小带宽，再交给较低带宽的信道。
3. 学习机必须区分选择性约束与限制性约束；约束放错位置，机器会"学成"另一件事。
4. 弈棋机的意义不在棋，而在于它是军事与政治决策机器的前身。
5. 国家管理机器的真正风险是被少数人用来控制多数人，而非机器自身兴风作浪。

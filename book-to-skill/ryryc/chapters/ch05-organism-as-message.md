# 第五章：作为消息的有机体

## Core Idea
把有机体看做消息。有机体是混乱、瓦解与死亡的对立面，就像消息是噪声的对立面一样。描述一个有机体，不是逐一说明其中的每一个分子并编入目录，而是回答关于其**模式**的问题：当有机体变得更完整时，模式就是意义更大而变化更少的东西。由此推出维纳关于个体性的核心判断：**躯体的个体性是火焰式的、形式的个体性，而不是石头式的、实体的个体性**；这种形式可以传送，可以改变，也可以复制。

## Frameworks Introduced

### 稳态作为模式维持 (Homeostasis as Pattern Maintenance)
- 生命体抗拒毁灭与衰退这一总流的过程，叫做稳态 (homeostasis)。
- 体温偏离正常水平一度即需注意，偏离十度必然死亡；血液中的氧、二氧化碳、盐分与荷尔蒙，都由负反馈机制调节。
- 稳态所保持的东西就是**模式**，它是"我们个体的同一性的试金石"。
- 身体组织不断更替：食物与空气变成血肉，血肉中的暂时性因素随排泄物排出体外。"我们无非是川流不息的江河中的漩涡"。

### 模式即消息 (Pattern as Message)
- 无线电除了传递声音模式别无他用；电视除了传递光模式别无他用。
- 若有可能传递人体的整个模式、人脑及其记忆以及记忆之间错综复杂关系的整个模式，并由一个假想的接收工具以适当材料重新体现，那么身心所表现的过程就能延续，并通过稳态过程保持其完整性。

### 物质运输与消息运输 (Transportation vs Communication)
- 建筑师监造异地建筑的例子：设计图与施工细则可由传真电报在一秒内送达副本；进度由每日摄影记录回传；批评与劝告可由电话、传真电报、电传打字机传达。
- 建筑师本人及其文件"可以非常有效地用消息传送来代替"，而这一传送不把物质粒子从线路一端转移到另一端。
- 人的语言所达到的地方，即知觉能力所达到的地方，也就是控制能力扩展所及、在一定意义上肉体存在扩展所及的地方。
- 物质运输与消息运输之间的区别，在任何理论意义上决不是固定不变和不可过渡的。

### 个体性作为过程的连续性 (Individuality as Continuity of Process)
- 同型孪生：青蛙受精卵第一次分裂的两个细胞分开后，各自长成完整的青蛙；人的同型孪、犰狳的四胞胎亦然。
- 人格分裂（普林斯在哈佛提出的女孩病历）：几个发展程度不同的人格交替出现，甚至部分并存。
- 示踪元素参与新陈代谢的现代方法表明：整个躯体及其任一组成部分的更新速度，都远比对过去设想的速度快得多。
- 有机体的生物学个体性，来自过程的某种连续性，来自对其过去发展结果的记忆；心理个体性则可比作计算机对程序带与记忆的保持能力。

### 再体现的物理代价 (Physical Cost of Reinstantiation)
- 一个生殖细胞中全部基因所传送的有效信息量，至少要传送不低于一整套《大英百科全书》的信息；细胞中非对称碳原子的数目所含信息量，远多于编纂一部百科全书所需的标点数目。
- 对人体进行任何扫描，都必然是一种穿透各部分的探针，会在其所经途径上破坏有关组织；在别处用别的材料再造，又须使有机体在改造期间保持稳定。
- 因此"不能用电报拍送某人"是技术困难：有机体在这种根本性改造期间难以维持生命。蝴蝶在蛹期所经历的改造，已是最接近的类比。
- 这个思想实验的用途不是预言"电报旅行"，而是说明：**通信的基本观念就是消息的运输**，物质与消息一起运输只是达到该目的的唯一可设想方式。

## Key Concepts
- **稳态 (Homeostasis)** — 以负反馈维持模式相对恒定的动态平衡。
- **模式 (Pattern)** — 有机体同一性的真正载体，可作消息传递。
- **消息运输 (Message Transport)** — 只传递组织与模式、不转移物质粒子的通信。
- **再体现 (Reinstantiation)** — 接收端用适当材料把模式重新实现为可运转的个体。
- **形式的个体性 (Formal Individuality)** — 火焰式、过程式的同一性，区别于石头式、质料式的同一性。

## Mental Models
- **江河中的漩涡**：形状持续存在，水分子不断更换；同一性靠模式而非质料。
- **火焰 vs 石头**：石头靠其物质块保持自身，火焰靠持续燃烧的过程保持自身。
- **遥控工地**：把"到场"拆成"感知 + 决策 + 指挥"，这三者都可以消息化，只有施工本身必须留在现场。

## Anti-patterns
- **把同一性寄托在质料上**：认为保住原来的物质才算保住这个人，于是看不见模式层面的延续与断裂。
- **把运输与通信看成绝对鸿沟**：一边否认任何消息化可能，一边又以为"上传"只是拷贝文件。
- **忽略接收端的再体现能力**：只计算信道容量，不问接收端有没有组织能力与生命维持条件把消息重新实现。
- **把扫描当作无损读取**：任何读取都要付出扰动代价。

## Key Takeaways
1. 生命是在熵增总流中的局部孤岛，靠稳态（负反馈）维持其模式。
2. 个体的同一性是模式的延续，而非质料的同一；因此原则上可被消息化。
3. 物质运输与消息运输之间没有绝对的理论界限，只有技术与生命维持上的实际界限。
4. 再体现信息需要极高的信息量与极小的扰动，这正是"电报传送人"的现实障碍。

# 第一章：历史上的控制论

## Core Idea
维纳把"通信"与"控制"归为同一类现象：向人、向动物、向机器发出命令，本质上都是发送消息；要判断命令是否生效，必须收回关于执行情况的消息。因此，工程上的控制理论不是机械学的一个分支，而是信息论的组成部分。控制论 (cybernetics) 一词取自希腊语"舵手"，指的正是这种关于通信与控制的科学。

## Frameworks Introduced

### 通信即控制 (Communication as Control)
- 命令是消息，执行回报也是消息；控制的闭环由"发出—执行—回传—修正"构成。
- 中介是人还是机器无关紧要：对我而言，我只知道发出了什么信号、收回了什么应答信号。
- 因此，人的、动物的、机械的控制系统可以用同一套语言描述。

### 信息即负熵 (Information as Negative Entropy)
- 消息集合本身具有熵；一条消息的信息量等于其概率的负对数，即该消息的负熵。
- 愈是可几的消息，提供的信息愈少；陈词滥调的意义不如伟大的诗篇。
- 通信过程天然趋向组织性降低与含义受损，控制就是与这种增熵趋势作斗争。

### 反馈回路 (Feedback Loop)
- 感觉接收器采集外界信息，中枢据此决策，效应器作用于外界，运动感觉器官再把结果送回中枢。
- 人取雪茄、驾驶汽车都依靠这种回路：不是精确指定每块肌肉，而是不断比较"实际演绩"与"目标"。

## Key Concepts
- **控制论 (Cybernetics)** — 研究动物、机器与有机体中通信和控制的一般规律。
- **消息 (Message)** — 模式与组织的一种形式，可被传输、存贮、变换。
- **熵 (Entropy)** — 组织解体的量度；孤立系统中单调增加。
- **负熵 (Negentropy)** — 组织性的量度，信息即是负熵。
- **演绩 (Performance)** — 系统实际做出的行为，是反馈比较的对象。

## Mental Models
- **"有效生活就是拥有足够的信息来生活"**：信息不是装饰，而是维持组织、应对偶然性的基本资源。
- **"人是束缚在自己感官所能知觉到的世界中的"**：任何控制系统的能力上限，首先由它的感受器与通道决定。
- **中介透明**：只要输入输出关系不变，信号经过人还是经过机器，不改变控制问题的结构。

## Anti-patterns
- 把命令当成控制：只发指令、不读回传，实际上是在单向广播。
- 把数据量当信息量：重复、可预测的内容传输再多，负熵也接近于零。
- 忽视通道损耗：以为消息会"原样"到达；每一次转导都可能永久丢失信息。

## Key Takeaways
1. 控制的前提是通信，通信的核心是回传。
2. 信息是负熵，只有降低不确定性的消息才有价值。
3. 人与机器在控制论意义上可类比，因为二者都靠反馈对抗熵增。
4. 分析任何系统，先画出它的感受器、决策器、效应器与回传路径。

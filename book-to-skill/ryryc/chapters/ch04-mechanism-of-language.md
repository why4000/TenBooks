# 第四章：语言的机制和历史

## Core Idea
通信理论不能回避语言。语言就是通信自身的别称，也是通信得以进行的信码 (code)。人与动物的差别不在"有无语言"，而在信码的精巧与任意程度：动物多半只能传达情绪与眼前事物，信码受物种约束、历久不变；人则能把任意声音约定为符号，表达关系、类与高级逻辑类型。维纳指出，语言不是生命体独有，机器也可以在一定限度内与人、与机器"交谈"。

## Frameworks Introduced

### 信码的精巧与任意性 (Elaborate and Arbitrary Code)
- 动物信号大多暂时、不存贮，译成人语多为感叹词；它们难以表达事物之间的复杂关系。
- 人类信码高度任意：声音与意义没有天然联系，因而可以约定、可以扩展、可以代际传递。
- 语言能力是"赋予人的可能性"，必须通过学习才成为有益的东西。

### 多级转导与信息逸失 (Multi-stage Transduction)
- 从发讯者到收讯者，消息要经过线路、变换、执行等多个阶段。
- 每两个阶段之间的转换都可能使信息逸失而永不再得；"除最后的或生效的阶段外"，中间任何环节都不是无损的。
- 线路能传送的最大信息量，不等于接收装置实际能使用的信息量。

### 语义过滤 (Semantic Filter)
- 从控制论看，语义上有意义的信息，是通过线路**以及**接收系统激活机构的信息，而非仅仅通过线路的信息。
- 同一段音乐，训练有素的音乐家能从中听出结构，缺乏训练者只听到声音；差别在接收端的组织能力。
- 因此，语义学规定了信息意义的范围，使其在通信系统中免于逸失。

## Key Concepts
- **信码 (Code)** — 把消息映射为可传输信号的约定系统。
- **任意性 (Arbitrariness)** — 符号与意义之间无必然联系，因而可被约定和改写。
- **转导 (Transduction)** — 消息在通道中被变换形式的过程。
- **语义信息 (Semantic Information)** — 能被接收方激活机构实际使用的信息。
- **信息逸失 (Information Loss)** — 转导过程中不可恢复的信息减少。

## Mental Models
- **通道容量 ≠ 可用信息**：一条链路能传多少比特，与接收者能理解多少，是两个问题。
- **接收者决定意义**：意义不在信号里，而在信号与接收结构的匹配中。
- **语言是协议，不是本能**：人会说话是可能性，会有效沟通是学习的结果。

## Anti-patterns
- **把"发出"当"送到"**：只检查发送端，不检查转导与接收端，误判沟通已完成。
- **用术语代替理解**：信码再精巧，若接收方没有对应的激活结构，也只是噪声。

## Key Takeaways
1. 语言是通信的信码系统，其力量来自精巧与任意性。
2. 信息在每一级转导中都可能永久损失，控制必须按"生效阶段"计量。
3. 语义信息取决于接收系统的组织能力，而非仅取决于信号本身。
4. 人—机—机之间的"语言"已在工程上成立，语言不再是生命的专属。

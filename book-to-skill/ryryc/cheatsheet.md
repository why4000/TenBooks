# Cheatsheet: 人有人的用处

## 决策规则
| 当你... | 做什么 |
|---|---|
| 认为某系统会自然变得更有秩序 | 先算熵账：它从哪里摄取负熵，把熵排到哪里 |
| 判断一条消息的价值 | 问它降低了多少不确定性；可预测、可复制的不是信息 |
| 命令下达后执行走样 | 审计反馈回路，检查回传是否测量实际演绩 |
| 组织对变化反应迟钝 | 诊断定型/学习：是否有修改策略的权限与时间 |
| 想靠固定职能提升效率 | 先问这是不是给人穿上了昆虫的紧身衣 |
| 讨论数字化/远程/复制 | 区分质料与模式；模式可消息化，但需接收端能再体现 |
| 设计规则、契约、法条 | 先消除歧义：可重复性是公平的先决条件 |
| 多个目标同时写进制度 | 显式设定权重；四套刑罚目标混用必然摇摆 |
| 评估保密或信息公开政策 | 区分自然噪声与有意堵塞，检查通信成本与伪通信激励 |
| 引入自动化/AI | 先按替代层级盘点，再用奴隶劳动基准估算就业冲击 |
| 技术已可行、制度未跟上 | 把过渡期单独规划，不要让"眼前有利"决定采用节奏 |
| 有人把对手想象成全能阴谋 | 检查是否落入摩尼教式思维；自然多半"精明但无恶意" |
| 判断信息资产该储藏还是流通 | 先算非守恒性：信息随熵增贬值，安全来自持续流通 |
| 要定保密方案预算 | 同时报出保护强度与解密延迟，两者相乘才是真实成本 |
| 通信出现故障 | 先分清自然噪声、有意堵塞、自身能力不足，再选对策 |
| 为残障者设计替代通道 | 先压缩到语义所需的那一部分，再交给较低带宽的信道 |
| 团队要求"统一思想"再搞科研 | 这是以绝对效忠替代坦白为怀，会损害科学诚实 |
| 反馈效果不佳 | 先查是否增益过载；过载表现为目的震颤或休息震颤 |

## 关键概念速查
- 控制论 = 关于通信与控制的科学，词源"舵手"
- 信息 = 负熵 = 概率的负对数
- 熵增 = 孤立系统趋向混沌；秩序是低概率状态
- 负熵 = 局部、暂时提高组织性，需持续投入能量与信息
- 反馈 = 用过去演绩调节未来行为
- 稳态 = 负反馈维持模式不变
- 定型 = 结构锁定、精确但不能应变
- 学习 = 策略层面的高阶反馈
- 模式 = 有机体同一性的真正载体（"江河中的漩涡"）
- 自动机 = 感觉器官 + 效应器官 + 中央决策器
- 第二次工业革命 = 替代低层判断与重复脑力
- 自动化 ≈ 奴隶劳动的经济效果
- 个体性 = 火焰式的形式，不是石头式的质料
- 信息 = 非守恒资产；流通才有价值，封存必贬值
- 姿势反馈 = 第二级反馈，与随意反馈反向，过载致休息震颤
- 感官替代 = 换信道不换语义，先把信息压缩到语义所需部分
- 国家管理机器 = 风险在"被谁使用"，不在机器自主
- 摩尼教之恶 = 把混乱看成一支会对等出招的军队

## Tells & Smells
- **Smell**: "信息是免费的" → 忽略观测与校验的物理代价，重演麦克斯韦妖的错觉。
- **Smell**: "只要不断扩张，问题就能解决" → 用新资源掩盖内部熵增，迟早碰到边界。
- **Smell**: "把每个人的职能事先定好，效率最高" → 蚂蚁模型，牺牲的是人的可塑性。
- **Smell**: "命令已经发了，为什么还没执行" → 只有下行、没有回传的单向控制。
- **Smell**: "多发论文/多发内容就是产出" → 不需要通讯的通讯，信号价值趋零。
- **Smell**: "对手在系统地、有意识地破坏我们" → 摩尼教式投射，会制造侦探式内耗。
- **Smell**: "自动化一定带来闲暇" → 跳过过渡期与分配问题，把技术可能性当成社会结果。
- **Smell**: "成果标密件锁进保险柜就安全了" → 封存武器式幻觉，十年后即与真实需要错位。
- **Smell**: "反馈越强越好，增益拉到最大" → 增益过载，正是目的震颤与帕金森式振荡的成因。
- **Tell**: 保密预算同时写清"多强"与"多久" → 时间是保密成本的正确度量。
- **Tell**: 能区分"自然界不改策略"与"人会改策略" → 科学诚实与博弈对策各归其位。
- **Tell**: 系统能说清"熵从哪来、排到哪去" → 它真正理解了自己的可持续性。
- **Tell**: 制度允许成员修改策略并有时间学习 → 学习模式在运转，而非定型。
- **Tell**: 规则可重复、判决可预期 → 法律的通信协议层是健康的。

# Cheatsheet: 毛泽东选集

## 矛盾分析速查
```
1. 承认矛盾普遍性
2. 分析矛盾特殊性（具体问题具体分析）
3. 抓主要矛盾
4. 抓矛盾的主要方面
5. 看矛盾转化条件
```

## 实践-认识循环
```
实践 → 认识（感性→理性）→ 再实践（检验）→ 再认识 → ...
```

## 决策规则
| 当你... | 做什么 |
|---|---|
| 面对复杂问题 | 矛盾分析，抓主要矛盾 |
| 做决策前 | 先调查研究 |
| 资源有限 | 集中优势兵力，各个击破 |
| 弱对强 | 持久战：防御→相持→反攻 |
| 制定政策 | 群众路线：从群众中来，到群众中去 |
| 理论与实际冲突 | 实事求是，从实际出发 |
| 组织作风普遍走偏 | 整风：反主观主义/宗派主义/党八股，惩前毖后、治病救人 |
| 总体资源处于劣势 | 集中优势兵力，先打弱敌，各个歼灭 |
| 守地方与歼灭有生力量冲突 | 以歼灭有生力量为主，不守一城一地 |
| 取得胜利或处于顺境 | 两个务必：谦虚谨慎、艰苦奋斗 |
| 内部冲突不知用说服还是强制 | 先判两类矛盾，人民内部用民主说服 |
| 多目标资源分配 | 统筹兼顾、适当安排，不只顾一头 |
| 学术或艺术分歧 | 百花齐放、百家争鸣，不用行政强制 |
| 与长期合作者共处 | 长期共存、互相监督 |

## 战略 vs 战术
| 层面 | 态度 | 方法 |
|---|---|---|
| 战略 | 藐视敌人 | 看全局、看长远 |
| 战术 | 重视敌人 | 看细节、看当下 |

## Tells & Smells
- **Smell**: "书上说的" → 本本主义，需实事求是。
- **Smell**: 平均用力 → 没有抓主要矛盾。
- **Smell**: 急于求成 → 速胜论，需持久战思维。
- **Smell**: 脱离群众 → 命令主义，需走群众路线。
- **Smell**: 空话连篇、言之无物 → 党八股，需整顿文风。
- **Smell**: 一斗就把事情斗乱 → 缺"团结——批评——团结"的团结愿望。
- **Smell**: 处处攻击、平分资源 → 没有集中优势兵力。
- **Smell**: 只顾一头、顾此失彼 → 缺统筹兼顾。
- **Tell**: 先调查再结论 → 实事求是在起作用。
- **Tell**: 抓最坏、中等、最好各一个样本 → 典型调查在起作用。

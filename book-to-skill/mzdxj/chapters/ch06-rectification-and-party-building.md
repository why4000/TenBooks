# Chapter 6: 整风与党的建设

## Core Idea
党的作风决定队伍能否"整齐"、步调能否一致。整风以反对主观主义、宗派主义、党八股为内容，以"惩前毖后、治病救人"为方针，用批评与自我批评改造思想方法，而不是整人。

## Frameworks Introduced
- **三大歪风**: 学风上的主观主义、党风上的宗派主义、文风上的党八股。"我们要把产生这种歪风的洞塞死"。整风即反主观主义、宗派主义、党八股。
- **惩前毖后、治病救人**: 对以前的错误"一定要揭发，不讲情面"，以科学态度分析批判；目的是"好像医生治病一样，完全是为了救人，而不是为了把人整死"。
- **一般号召与个别指导相结合**: 只发一般号召而不突破一点、取得经验，号召就有"归于落空"的危险；应选择二三个单位深入研究，再用经验指导其他单位。
- **领导骨干与广大群众相结合**: 团结积极分子作为骨干，提高中间分子，争取落后分子。
- **为人民服务**: "彻底地为人民的利益工作"；有缺点就不怕别人批评指出，"只要你说得对，我们就改正"。

## Key Concepts
- **学风/党风/文风**: 三者都是党的作风；学风是"对待马克思列宁主义的态度问题"。
- **党八股**: 空话连篇、言之无物、只搬用名词术语的宣传形式。
- **批评与自我批评**: 揭发错误与帮助改正的统一。

## Mental Models
- 整风像医生做手术：割掉阑尾是为了救人，不是把人整死。
- 一般号召像撒网，个别指导像先试捕一网，看清鱼情再全面下网。

## Anti-patterns
- 主观主义：凭"想当然"发号施令，不调查现状与历史。
- 宗派主义："不准犯错误的人革命"，把犯错误与反革命混为一谈。
- 党八股：内容空洞、专讲形式。
- "残酷斗争，无情打击"：一斗就把事情斗乱。

## Key Takeaways
1. 作风不正，队伍就不能整齐。
2. 整风的目的在救人，不在整人。
3. 一般号召必须落到个别指导上。
4. 为人民服务，就要为人民的利益坚持好的、改正错的。

# Chapter 3: 实事求是与反对本本主义

## Core Idea
"实事求是"是马克思主义中国化的精髓——从实际出发，理论联系实际，在实践中检验真理。反对本本主义（教条主义）。

## Frameworks Introduced
- **实事求是**: "实事"=客观事物，"是"=规律性，"求"=研究。
- **反对本本主义**: 不要从书本出发，要从实际出发；"没有调查，没有发言权"。
- **调查研究**: 了解实际情况的根本方法。

## Key Concepts
- **教条主义**: 从书本/理论出发，脱离实际。
- **经验主义**: 从局部经验出发，轻视理论。
- **调查研究**: 一切结论产生于调查的末尾，而不是开头。

## Mental Models
- 实事求是像看病：先望闻问切（调查），再对症下药（决策）。
- 本本主义像刻舟求剑：只记书本，不顾实际变化。

## Anti-patterns
- 没有调查就下结论。
- 照搬外国经验/书本理论。

## Key Takeaways
1. 没有调查，没有发言权。
2. 从实际出发，不从书本出发。
3. 理论联系实际。
4. 在实践中检验和发展真理。

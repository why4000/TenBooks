# Chapter 5: 论持久战与战略战术

## Core Idea
弱对强的斗争不能速胜，必须经过战略防御→战略相持→战略反攻三阶段。在相持中转化力量对比，最终取胜。

## Frameworks Introduced
- **持久战三阶段**:
  1. 战略防御：敌强我弱，保存实力，消耗敌人。
  2. 战略相持：力量对比转变，敌我平衡。
  3. 战略反攻：我强敌弱，转入反攻。
- **战略战术原则**:
  - 战略上藐视敌人，战术上重视敌人。
  - 集中优势兵力，各个歼灭敌人。
  - 游击战十六字诀：敌进我退，敌驻我扰，敌疲我打，敌退我追。

## Key Concepts
- **速胜论 vs 亡国论**: 两个错误极端，正确的是持久战。
- **主动性、灵活性、计划性**: 战争指导的三原则。

## Mental Models
- 持久战像拔河：开始对方力大，稳住阵脚；相持中消耗对方；最后发力反攻。
- 集中优势兵力像凸透镜：把分散的阳光聚焦到一点点燃纸。

## Anti-patterns
- 速胜论：低估敌人，急于决战。
- 亡国论：高估敌人，丧失信心。

## Key Takeaways
1. 弱对强必须经过相持阶段。
2. 在相持中转化力量对比。
3. 战略上藐视，战术上重视。
4. 集中优势兵力，各个击破。

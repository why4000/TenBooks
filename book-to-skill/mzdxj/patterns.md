# Patterns

## Pattern 1: 矛盾分析 (Contradiction Analysis)
**When to use**: 面对复杂问题找关键点。

**How**:
1. 承认矛盾普遍性。
2. 分析矛盾特殊性（具体问题具体分析）。
3. 找出主要矛盾。
4. 在主要矛盾中抓主要方面。
5. 分析矛盾转化的条件。

## Pattern 2: 实践-认识循环 (Practice-Knowledge Cycle)
**When to use**: 学习新知识、解决新问题。

**How**:
1. 实践（去做）。
2. 总结认识（从经验到理论）。
3. 再实践（用理论指导）。
4. 再认识（修正理论）。
5. 循环上升。

## Pattern 3: 调查研究 (Investigation First)
**When to use**: 做决策前。

**How**:
1. 不急于下结论。
2. 深入实际调查。
3. 收集第一手材料。
4. 分析材料，得出结论。
5. 在实践中检验结论。

## Pattern 4: 群众路线工作法 (Mass Line Method)
**When to use**: 制定政策、推动工作。

**How**:
1. 从群众中来：收集群众意见。
2. 集中起来：形成系统政策。
3. 到群众中去：宣传实施。
4. 收集反馈：修正政策。

## Pattern 5: 持久战策略 (Protracted Strategy)
**When to use**: 弱对强的长期竞争。

**How**:
1. 战略防御：保存实力，消耗对方。
2. 战略相持：转化力量对比。
3. 战略反攻：转入进攻。

## Pattern 6: 集中优势兵力 (Concentrate Superior Force)
**When to use**: 资源有限时。

**How**:
1. 识别关键目标。
2. 集中主要资源于一点。
3. 各个击破，不分散兵力。

## Pattern 7: 整风式组织纠偏流程 (Rectification)
**When to use**: 组织内出现普遍的作风或思想偏差。

**How**:
1. 界定歪风：学风（主观主义）、党风（宗派主义）、文风（党八股）。
2. 改造学习：用理论与实际统一的标准对照现状、历史与经验。
3. 批评与自我批评：揭发错误不讲情面，以科学态度分析。
4. 惩前毖后、治病救人：帮助改正，不搞"残酷斗争，无情打击"。
5. 一般号召加个别指导：抓二三个单位，取得经验再推广。
6. 把新作风固定下来，影响组织之外。

## Pattern 8: 歼灭战资源配置法 (Annihilation)
**When to use**: 总体资源劣势，不能处处设防。

**How**:
1. 以消灭对方有生力量或解决关键问题为目标，不以守住全部阵地为目标。
2. 选较弱、援少、地形与民情有利的一路。
3. 集中三至六倍优势于一点，四面包围。
4. 以少数力量牵制其余，阻其增援。
5. 力求全歼、速决，用缴获补充自己。
6. 利用间隙休整，再打下一仗。

## Pattern 9: 两类矛盾判定与处置流程 (Two Contradictions)
**When to use**: 内部冲突，需决定用说服还是强制。

**How**:
1. 先定"人民/敌人"的范围（随时期变化）。
2. 判性质：对抗性还是非对抗性。
3. 敌我矛盾：分清敌我，用专政。
4. 人民内部矛盾：分清是非，用民主、讨论、批评、说服。
5. 走"团结——批评——团结"：从团结愿望出发，解决后达到新团结。
6. 防转化：处理不当，非对抗性也会变成对抗。

## Pattern 10: 统筹兼顾的取舍法 (Balanced Allocation)
**When to use**: 多目标、多主体的资源分配。

**How**:
1. 列全相关关系（十大关系或本场景的主要几对）。
2. 明确基本方针：调动一切积极因素。
3. 找"真想假想"的检验指标：看投资、时间比例落在哪里。
4. 补短板：如多发展农业、轻工业以稳固重工业。
5. 统筹安排，不只顾一头。
6. 定期算总账，看长期是否划算。

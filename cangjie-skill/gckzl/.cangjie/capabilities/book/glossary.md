# Book Glossary

- 传递函数: 零初始条件下输出与输入的拉氏变换比
- 拉氏变换: 时间域到复频域的积分变换
- 极点: 传递函数分母的根，决定稳定与快慢
- 零点: 传递函数分子的根，影响波形
- 反馈: 测量输出并用偏差纠正
- 开环: 不测量输出，按模型控制
- 闭环: 用反馈构成回路
- 偏差信号: 输入与反馈量之差
- 乃氏判据: 开环轨迹绕 -1 点圈数判稳定
- 路斯—胡尔维茨判据: 用系数判根的位置
- 时滞: 依赖过去时刻状态的纯延迟
- 微分差分方程: 含导数与延迟项的方程
- 萨奇图: 分离时滞项的稳定性图解法
- 绝对稳定: 对任意时滞都稳定
- 平稳随机过程: 统计性质不随时间平移改变
- 相关函数: 不同时刻取值的关联程度
- 功率谱: 相关函数的傅氏变换
- 白噪声: 功率谱为常数的随机过程
- 维纳—辛钦关系: 相关函数与功率谱互换
- 描述函数: 非线性环节的基波等效特性
- 极限环: 相平面孤立闭轨，自激振荡
- 自行镇定: 越界换参数，保留稳定形式
- 适应环境: 连续调整参数以适应干扰
- 复合方法: 多路线束组合提高可靠性
- 复原机构: 随机重排抑制误差扩散
- 平均平方误差: 最优过滤器的优化目标

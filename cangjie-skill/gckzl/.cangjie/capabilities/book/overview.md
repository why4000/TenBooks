# Book Overview

## 主旨
把工程控制从零散经验提升为技术科学：用传递函数统一描述系统，用反馈替代精确模型，用稳定性判据守住底线，再逐层处理时滞、随机性、非线性与可靠性。

## 骨架
1. 建模入口：拉氏变换把微分方程化为代数方程，传递函数刻画输入—输出。
2. 反馈：测量—比较—纠正，闭环 `F1/(1+F1F2)`，三条设计准则。
3. 稳定性：极点全在左半平面；路斯判据与乃氏判据互为代数/图解视角。
4. 非理想因素：时滞（萨奇图）、随机输入（功率谱）、非线性（极限环）、变系数。
5. 设计方法：摄动、指定积分条件、在线寻优、维纳过滤。
6. 可靠性：自行镇定的参数搜索；冯·诺伊曼的冗余与复原机构。

## 关键论点
- 稳定性的提法必须绑定工作点、扰动大小与判据。
- 反馈用误差替代精确模型，能同时改善精度与反应速度，但侵蚀稳定裕度。
- 时滞不改变稳态增益，却持续消耗相位裕度。
- 随机输入下，设计对象是输出的统计性质。
- 弱非线性可线性化，接近共振时不可。
- 可靠性可以来自运行中的试错机制，也可以来自纠错结构。
- 冗余必须配纠错，否则只是复制错误。

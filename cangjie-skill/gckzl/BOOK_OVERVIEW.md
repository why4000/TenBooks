# BOOK_OVERVIEW.md — 工程控制论（新世纪版）

## 元信息
- **书名**: 工程控制论（新世纪版）
- **作者**: 钱学森 (H. S. Tsien)
- **类型**: 技术科学 / 控制工程 / 系统科学
- **版本**: 原书英文版 1954 年 McGraw-Hill；汉文版 1957 年；新世纪版 2007 年上海交通大学出版社
- **核心命题**: 把工程实践中的控制与调节经验整理成一门技术科学——用传递函数、反馈与稳定性理论统一描述各类自动控制系统，并给出可执行的设计判据。

## 一、结构
全书 18 章，按"建模 → 线性设计 → 非理想因素 → 综合方法 → 可靠性"展开：

1. **问题设定与方法论（引言、ch1–2）**
   - 引言：常系数线性 / 变系数线性 / 非线性三分类；工程近似的合法性。
   - 拉氏变换法：把微分方程翻译成代数方程，建立传递函数入口。
2. **线性系统与反馈（ch3–7）**
   - 常系数线性系统：传递函数、极点零点、伯德图/乃氏图。
   - 反馈伺服系统：开环 vs 闭环、三条设计准则、乃氏稳定性判据。
   - 不互相影响的控制：多变量解耦。
   - 交流伺服与振荡控制伺服：用振荡把非线性线性化。
   - 采样伺服系统：离散采样下的稳定性。
3. **非理想因素（ch8–12）**
   - 有时滞的线性系统：微分差分方程、萨奇图、火箭燃烧不稳定。
   - 平稳随机输入下的线性系统：相关函数、功率谱、白噪声。
   - 继电器伺服系统：非线性开关、颤震、最优开关曲线。
   - 非线性系统：弱非线性、极限环、跳跃、频率缩减与侵占。
   - 变系数线性系统：参数随时间变化时的稳定性提法。
4. **综合与设计方法（ch13–16）**
   - 利用摄动理论的控制设计。
   - 满足指定积分条件的控制设计：先定性能，再反求结构。
   - 自动寻求最优运转点的控制系统：在线搜索极值。
   - 噪声过滤的设计原理：维纳—阔尔莫果洛夫最优过滤。
5. **可靠性与误差（ch17–18）**
   - 自行镇定和适应环境的系统：越界切换参数、随机试错。
   - 误差的控制：冯·诺伊曼复合方法、冗余与复原机构。

## 二、核心术语骨架

- 时滞 / 微分差分方程 / 萨奇图 / 绝对稳定
- 平稳随机过程 / 相关函数 / 功率谱 / 白噪声 / 维纳—辛钦关系

- 冗余 / 复合方法 / 复原机构 / 平均平方误差

## 三、原书关键任务清单
1. 把物理系统抽象为传递函数，并用极点零点判断动态特性。
2. 用反馈替代开环，按稳定性、快速性、精度三条准则设计回路。
3. 用路斯判据或乃氏图判定闭环稳定性，并给出稳定裕度。
4. 在存在纯滞后时，用萨奇图分析临界时滞，争取绝对稳定。
5. 在随机输入下，用相关函数与功率谱计算输出的统计性质。
6. 识别非线性现象（极限环、跳跃、频率侵占），避免盲目线性化。
7. 用维纳过滤理论在噪声中提取信号，使平均平方误差最小。
8. 用自行镇定机制或冯·诺伊曼冗余结构提升复杂系统可靠性。

# 英雄之旅映射 (hero-journey-mapping)

## R — Rationale
所有文化的英雄神话共享同一深层结构。用这个结构分析叙事，能快速把握其心理意义。

## I — Intent
将叙事映射到启程→启蒙→考验→归来四阶段，识别关键节点和缺失环节。

## A1 — 原书案例
坎贝尔分析全球神话，发现都遵循同一模式：召唤→跨越阈限→考验→恩赐→归来。

## A2 — 适用边界
- 与 call-recognition 的区分：本能力是整体映射，后者聚焦召唤阶段。
- 与 belly-of-whale-transformation 的区分：本能力是全结构，后者聚焦转变节点。

## E — Execution
1. 识别"英雄"（主体）。
2. 映射四阶段：启程（召唤→阈限）→启蒙（考验→恩赐）→考验→归来。
3. 标注每个阶段的关键事件。
4. 识别缺失或薄弱的阶段。

**输入**: 一个叙事/历程
**输出**: 四阶段映射 + 关键节点
**完成标准**: 四阶段均有对应，薄弱环节被标注

## B — Boundaries
- 不是所有故事完美契合——它是分析工具，不是模板。
- 不要把它当成功学公式。

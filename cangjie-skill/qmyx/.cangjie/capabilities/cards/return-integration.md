# 归来整合 (return-integration)

## R — Rationale
获得终极恩赐后必须归来，将恩赐带回社群。归来也是旅程的一部分，需要整合。

## I — Intent
将冒险世界获得的恩赐带回日常，整合为两个世界的主宰。

## A1 — 原书案例
英雄获得恩赐后不愿归来，需要外界救援才能跨越回归阈限。

## E — Execution
1. 认识到归来是旅程的一部分。
2. 寻找外界救援帮助整合。
3. 将新认知转化为日常语言和行动。
4. 成为两个世界的主宰。

**输入**: 一次获得新认知的经历
**输出**: 整合方案
**完成标准**: 新认知转化为日常行动

## B — Boundaries
- 不要把新认知藏起来——恩赐是为了分享。

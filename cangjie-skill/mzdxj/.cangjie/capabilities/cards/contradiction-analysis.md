# 矛盾分析 (contradiction-analysis)

## R — Rationale
矛盾是事物发展的根本动力。复杂问题的关键在于抓住主要矛盾和矛盾的主要方面。

## I — Intent
承认矛盾普遍性，分析特殊性，抓主要矛盾和矛盾的主要方面，注意转化条件。

## A1 — 原书案例
毛泽东在《矛盾论》中提出：具体问题具体分析是马克思主义活的灵魂。

## E — Execution
1. 承认矛盾普遍性（问题总有矛盾）。
2. 分析矛盾特殊性（具体问题具体分析）。
3. 找出主要矛盾（起决定作用的）。
4. 抓矛盾的主要方面（决定性质的）。
5. 分析矛盾双方转化的条件。

**输入**: 一个复杂问题
**输出**: 主要矛盾 + 主要方面 + 转化条件
**完成标准**: 明确主要矛盾和主要方面

## B — Boundaries
- 矛盾分析是方法论，不是教条。
- 需要结合实践检验。

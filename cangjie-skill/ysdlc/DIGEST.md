# DIGEST — 一生的旅程

## 一句话精华
人性在商业当中永远是最重要的一件事——危机中亲自直面、底层赋予工作意义、讲故事优先、主动担责、把不可能办成、外行压制自尊，并始终守住内心的童真。

## 五项能力
1. 人性化危机领导 — 亲自致电 + 当天整改，不让公关过滤人性
2. 讲故事优先重构 — 赛事会取消，故事不会
3. 主动担责 — 全场沉默时第一个站起来
4. 把不可能办成 — 追问约束边界，找不收钱式替代路径
5. 外行领导入场 — 压制自尊，多提问，用作品进圈子

## 核心洞察
1. 真诚是最高级的沟通：一边哭泣一边向遇难者父亲道歉
2. 意义自赋：为辛纳屈买漱口水也"一路跑着去跑着回来"
3. 竞争力在叙事：卡尔加里比赛取消，转挖运动员故事，收视率创新高
4. 担责是最快的信任投资：漏拍撞线镜头后主动起身，鲁尼另眼相看
5. "不行"是约束的表述而非终点：平壤不收钱转播谈成
6. 假装内行是高位外行最大的风险；《双峰镇》剧本没看懂也敢拍板"肯定不一样"
7. 人才就是把看似办不成的事办成的人

## 关键判断
- 危机中"人"先于"公司"；责任可后续厘清，人的痛苦不能等
- 资源失效时，人的故事是最可靠的替补内容
- 追责现场站出来的成本最低、信任收益最大
- 禁令有边界，边界内常有各方都赢的方案
- 混进封闭圈子最有效的方法是做事被看到，不是请客送礼
- 无论取得何种头衔，你仍是那个一直以来的自己

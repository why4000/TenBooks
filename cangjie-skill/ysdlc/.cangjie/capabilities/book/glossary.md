# Book Glossary

- 人性化危机领导: 危机中亲自直面受害者并当天整改
- 鳄鱼事件: 3 岁男孩被鳄鱼拖走，艾格亲自致电、围起所有湖泊
- 赋予工作意义: 工作无大小，意义由自己赋予
- 鲁尼: 导师，完美主义者；讲故事优先、为了更好不惜一切
- 讲故事优先: 首要职责是讲故事，而不是播放赛事
- 为了更好不惜一切: 把事做到极致的态度
- 主动担责: 追责现场第一个站起来说"是我的责任"
- 信任资本: 靠担责与办成事累积的个人信用
- 拆解约束: 追问"不行"的边界，找替代路径办成
- 外行领导: 高位外行空降；压制自尊、不假装内行
- 提问式学习: 抑制假装知道的冲动，多向对方提问
- 守住童真: 无论走到哪一阶段，你还是那个一直以来的自己

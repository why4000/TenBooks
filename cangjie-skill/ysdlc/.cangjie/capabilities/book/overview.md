# Book Overview

## 主旨
《一生的旅程》(The Ride of a Lifetime) 演讲实录主线：罗伯特·艾格 (Robert Iger) 从 ABC 场工到迪士尼 CEO，靠的是人性化危机领导、赋予工作意义、讲故事优先、主动担责、把不可能办成、外行压制自尊——人性在商业当中永远是最重要的一件事。

## 骨架
1. 开篇危机：奥兰多枪击案与鳄鱼事件，亲自致电、当天围湖
2. 底层起步：工薪家庭、场工、辛纳屈漱口水——意义由自己赋予
3. 体育部岁月：鲁尼两条教诲（讲故事优先、为了更好不惜一切）；平壤不收钱转播；漏拍撞线主动担责；卡尔加里转挖运动员故事收视创新高
4. 好莱坞外行：不让自尊心占上风、多提问；《成长的烦恼》《双峰镇》；做事进圈子
5. 结尾速览：战略白板三板块、退休延期至 2021、守住童真、寄望中国 IP 产业

## 关键论点
- 危机中"人"先于"公司"，亲自直面并当天整改
- 对琐碎工作的投入度是区分人的分水岭
- 竞争力在叙事不在转播；赛事会取消，故事不会
- 追责现场第一个站出来的人最快积累信任资本
- "不行"是约束的表述而非终点，拆解变量就能找到门
- 高位外行最大的风险是假装内行；承认不懂+多提问最快建立判断
- 无论取得何种头衔，你还是那个一直以来的自己

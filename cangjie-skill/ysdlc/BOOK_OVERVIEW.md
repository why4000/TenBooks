# BOOK_OVERVIEW.md — 一生的旅程

## 元信息
- **书名**: 一生的旅程 (The Ride of a Lifetime)
- **作者**: 罗伯特·艾格 (Robert Iger)，迪士尼 CEO
- **类型**: 领导力/商业传记
- **材料性质**: 约 1.9 万字演讲实录（讲书稿），非全书；覆盖主线故事与领导力要点
- **核心命题**: 人性在商业当中永远是最重要的一件事——从底层场工到迪士尼 CEO，靠的是赋予工作意义、讲故事优先、主动担责、把不可能办成、外行入场压制自尊，并始终守住内心的童真。

## 一、结构
演讲实录主线五段：
1. 开篇危机（2016 上海迪士尼开幕；奥兰多夜总会枪击案；3 岁男孩鳄鱼事件；亲自致电家属、当天围湖）
2. 底层起步（工薪家庭、父亲爱书后患狂躁症；叔叔病友牵线进 ABC；场工；辛纳屈漱口水与镀金打火机）
3. ABC 体育部岁月（导师鲁尼两条教诲；平壤乒乓球世锦赛不收钱转播；撞线镜头漏拍主动担责；大都会收购与放权一线；卡尔加里冬奥会转挖运动员故事）
4. 好莱坞外行领导（不让自尊心占上风、多提问；《成长的烦恼》《美国家庭滑稽录像》《双峰镇》；《警察摇滚》之败；做事进圈子）
5. 迪士尼主线速览（战略白板：内容/科技/实体三板块；退休延期至 2021；守住童真；寄望中国 IP 产业）

## 二、核心术语骨架
- 人性化危机领导/鳄鱼事件/亲自致电
- 赋予工作意义/场工起步
- 讲故事优先/为了更好不惜一切（鲁尼）
- 主动担责/信任资本
- 拆解约束/把不可能办成（平壤）
- 外行领导/提问式学习（《双峰镇》）
- 守住童真

## 三、原书关键任务清单
1. 危机中亲自直面受害者，当天启动整改
2. 把"转播赛事"重构为"讲故事"，突破资源失效
3. 追责现场主动站出来担责，积累信任资本
4. 把"禁令/不可能"拆解成约束变量，找替代路径办成
5. 外行高位入场时压制自尊、提问式学习、用作品进入圈子

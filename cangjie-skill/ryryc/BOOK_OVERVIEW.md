# BOOK_OVERVIEW.md — 人有人的用处

## 元信息
- **书名**: 人有人的用处（The Human Use of Human Beings）
- **作者**: N. 维纳 (Norbert Wiener)
- **类型**: 控制论 / 科学哲学 / 社会分析
- **核心命题**: 社会只能通过消息与通信设备来理解；生命、机器与社会都是对抗熵增的局部负熵过程，而第二次工业革命将把这一过程推入劳动结构与社会政策的核心。

## 一、结构
全书 11 章，核心线索：
1. 控制论的起点：通信与控制归一，信息即负熵（ch1）
2. 熵、进步与麦克斯韦妖：秩序需要代价（ch2）
3. 两种通信行为模式：定型与学习（ch3）
4. 语言的机制：信码、转导与语义（ch4）
5. 有机体作为消息：稳态与模式同一性（ch5）
6. 法律作为对通信的道德控制（ch6）
7. 保密、专利与信息商品化（ch7）
8. 知识分子与科学家的责任（ch8）
9. 两次工业革命与自动化的社会冲击（ch9）
10. 通信机器与学习机的未来（ch10）
11. 语言、混乱与有意堵塞（ch11）

## 二、核心术语骨架
- 控制论 / 通信即控制
- 熵 / 负熵 / 信息
- 反馈 / 稳态
- 定型 / 学习 / 策略反馈
- 信码 / 语义信息 / 信息逸失
- 模式 / 有机体即消息
- 通信堵塞 / 伪通信
- 自动机 / 第二次工业革命

## 三、原书关键任务清单
1. 用熵账本判断系统与社会的"进步"是否可持续
2. 把有机体、组织与社会建模为消息与通信过程
3. 区分定型与学习两种模式，诊断组织僵化
4. 用控制论视角评估保密、专利、媒体等社会政策
5. 评估自动化对劳动结构的冲击并规划过渡

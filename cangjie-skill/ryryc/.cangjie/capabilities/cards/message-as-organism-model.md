# 消息化有机体模型 (message-as-organism-model)

## R — Rationale
有机体是混乱、瓦解与死亡的对立面，就像消息是噪音的对立面。维持生命的不是固定质料，而是模式：身体组织不断更替，模式却延续。既然模式可以作为消息被传输，那么"物质运输"与"信息运输"之间就不存在理论上的固定鸿沟；把人的感知与行动力以消息方式延伸到远方，已在部分意义上扩展了人的存在。

## I — Intent
把有机体、组织或远程协作场景拆成"质料"与"模式"，用稳态与反馈解释其同一性，并判断哪些环节可以由信息运输替代物质运输、哪些必须保留物质承载。

## A1 — 原书案例
维纳写道："我们无非是川流不息的江河中的漩涡。我们不是固定不变的质料，而是自身永存的模式。"稳态 (homeostasis) 通过负反馈维持体温、血氧、盐分等变量，保住的是模式而非材料。他又举建筑师为例：建筑师在欧洲监造美国的建筑，无需寄送建筑材料，只需用传真电报传送设计图、施工细则与每日摄影记录，用电话或电传打字机下达批评；本人与文件的传送，可以非常有效地由消息传送代替。

## E — Execution
1. 把对象拆成质料（具体物质载体）与模式（结构、关系、功能、记忆）。
2. 判断维持其同一性的究竟是哪一部分；若为模式，则原则上可消息化。
3. 画出其通信回路与稳态机制：感受器、决策器、效应器、回传路径。
4. 列出模式传输所需的通道、存贮介质与再体现条件。
5. 判断哪些环节可改为信息运输，哪些必须保留物质运输（如现场施工、物理交付）。
6. 检查接收端是否具备把消息重新体现为可用模式的组织能力。
7. 给出方案与边界：可替代部分、必须保留部分、失败模式。

**输入**: 一个有机体/组织/远程协作场景 + 其同一性判据
**输出**: 质料—模式分解 + 通信回路图 + 消息化方案与保留清单
**完成标准**: 明确"同一性靠什么维持、哪些环节可替代、再体现需要什么条件、哪里会失效"

## B — Boundaries
- 模式传输不等于意识、人格或主观体验的复制；维纳本人只把它当作"隐喻"和科学幻想式的推论。
- 若接收端缺乏相应的组织能力，传过去的只是信号，不是模式。
- 不能据此推断所有物质过程都可信息化；物质运输与信息运输的界限可以移动，但不是无限可移。
- 用于组织分析时，需另配权力、激励与信任等非通信变量。

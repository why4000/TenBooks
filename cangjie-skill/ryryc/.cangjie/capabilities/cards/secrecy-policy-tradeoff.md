# 保密政策权衡 (secrecy-policy-tradeoff)

## R — Rationale

维纳对保密的判断建立在信息的非商品性上：信息不像能量或黄金那样守恒，它在流通中增值、在封锁中贬值。第七章举了两个硬例证。其一是原子弹：制造的可能性已经公开，任何知道“这件事有答案”的科学家，就等于走完了通往答案的一大段路；把知识锁进图书馆，并不能保证安全——“对于人脑说来，没有马其诺防线”。其二是储藏：武器会过时，信息贬值更快，储藏等于主动落后。再加上三个保密项目重复解同一积分方程、耽误半年到一年的案例，保密政策必须按“重复成本 + 时间延误 + 拼接损失”来定价，而不能默认“越密越安全”。

## I — Intent

对一项保密政策、专利策略、科研数据共享或情报分割方案做权衡评估，回答：保护什么、保护多久、代价多大、是否有更便宜的分层开放方案。

## A1 — 原书案例

- **原子弹秘密**（第七章）：维纳指出，制造原子弹的可能性已不是秘密；科学家只要知道“有答案”，就已接近答案的一半。保密能拖延，但不能取消知识的可达性。
- **“没有马其诺防线”**（第七章）：静态防线挡不住人脑的再发现；把成果标为密件存进图书馆，只是把风险延后。
- **三个项目的重复积分方程**（第七章）：保密级别不同导致三方各自重做，合计延误半年至一年；这是保密账单上最具体的一笔。
- **武器储藏会过时**（第七章）：储藏的信息与武器一样会贬值，且贬值速度可能更快。

## E — Execution

1. **分类保护对象**：区分“可能性存在”“原理”“实现细节”“时间表/部署参数”四类，不同类别的保密价值差异极大。
2. **估重复概率**：列出可能独立重做的团队数量、他们的能力与动机，估计重复发现概率。
3. **算时间账**：估算封锁带来的延误月数，并对比该秘密的自然寿命（多久后会被替代或公开）。
4. **算拼接损失**：判断分割是否使跨部门无法把信息组合成有效判断。
5. **算流通收益**：列出开放能带来的复用、校验、人才流动与标准形成收益。
6. **设计方案**：优先“分层 + 限时 + 可审计”，而不是“全密/全开”的二选一；写明复审日期与降密条件。

**输入**
- 保密清单与分级理由
- 涉及团队、地点、保密级别矩阵
- 已知的重复项目或疑似重复项目
- 计划时间窗与替代技术时间表

**输出**
- 权衡表：保护对象 / 重复成本 / 延误成本 / 拼接损失 / 流通收益 / 建议等级 / 到期日
- 一份分层开放方案（谁在什么条件下、何时可获得什么）
- 复审日历与降密触发条件

**完成标准**
- 每项秘密都标注保护对象、成本估算与到期日，不得存在“永久保密”的默认项
- 至少一项从“永久保密”改为“限时/分层”，并说明依据
- 给出一个泄露情景的损失估计与一个重复发现的时间估计
- 明确区分“战术性短期秘密”与“基础科学知识”

## B — Boundaries

- 不处理涉及人身安全的具体情报来源与行动细节；那属于专业情报流程。
- 不替代法律合规与出口管制审查。
- 对真正的短期战术秘密，只给原则性建议，不做具体操作设计。
- 不能把“开放”本身当目的；开放也有噪声、误用与注意力成本。

# Book Glossary

- 控制论: 关于通信与控制的科学，词源"舵手"
- 熵: 组织解体与不确定性的量度
- 负熵: 组织性与秩序的量度
- 信息: 消息携带的负熵，概率的负对数
- 消息: 模式与组织的一种形式
- 反馈: 用过去演绩调节未来行为
- 稳态: 负反馈维持模式相对恒定
- 定型: 结构锁定、不可修改的行为
- 学习: 修改总策略的高阶反馈
- 信码: 消息与信号的约定映射
- 语义信息: 能通过接收激活机构的信息
- 麦克斯韦妖: 说明信息有物理代价的假想装置
- 模式: 有机体同一性的真正载体
- 通信堵塞: 有意阻断或扰乱对方消息
- 伪通信: 为声望而非内容而发的通信
- 自动机: 感觉+效应+中央决策的控制机器
- 第二次工业革命: 以反馈与计算机替代低层判断
- 奥古斯丁之恶: 恶是善的欠缺与混乱

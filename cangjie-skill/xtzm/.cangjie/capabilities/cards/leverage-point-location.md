# 杠杆点定位 (leverage-point-location)

## R — Rationale
在系统中，有些位置施加小变化就能导致大转变（杠杆点），有些位置费很大劲效果甚微。定位杠杆点是有效干预的关键。

## I — Intent
从12大杠杆点中定位最有效的干预点。

## A1 — 原书案例
数字（最弱）：调税率参数，效果有限。
信息流（第6）：给消费者产品能耗信息，改变购买行为，效应远大于调参数。
范式（第2）：改变"增长=好"的信念，整个系统行为根本改变。

## A2 — 适用边界
- 与 feedback-loop-analysis 的区分：本能力是干预，后者是诊断。

## E — Execution
1. 从最弱杠杆点开始检查：数字→缓冲器→结构→延迟→回路→信息流→规则→自组织→目标→范式→超越范式。
2. 在每一层问：我能在这里改变什么？
3. 在能改变的最高杠杆点上行动。
4. 预期：越往上层，效应越大，阻力也越大。

**输入**: 一个需要干预的系统
**输出**: 推荐的杠杆点 + 干预方案
**完成标准**: 推荐的杠杆点是当前能改变的最高层

## B — Boundaries
- 高层杠杆点（范式、目标）难改变，需长期努力。
- 不要因为低层容易就只在低层行动。

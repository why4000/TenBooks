# 反馈回路分析 (feedback-loop-analysis)

## R — Rationale
系统行为由反馈结构决定。理解系统动态行为的第一步是识别存量、流量和反馈回路。

## I — Intent
识别系统的存量、流量和调节/增强反馈回路，分析其动态行为模式。

## A1 — 原书案例
恒温器：温度（存量）低于设定值→加热（流入）→达到设定值→停止。调节回路。
复利：本金（存量）产生利息（流入）→本金增加→利息增加。增强回路。

## A2 — 适用边界
- 与 archetype-matching 的区分：本能力是基础分析，后者是模式匹配。
- 与 leverage-point-location 的区分：本能力是诊断，后者是干预。

## E — Execution
1. 识别存量（累积的量）。
2. 识别流入和流出（流量）。
3. 问：存量变化如何反过来影响流量？→ 反馈回路。
4. 判断回路类型：调节（趋向目标）还是增强（放大变化）。
5. 检查延迟——延迟导致振荡。
6. 预测行为模式。

**输入**: 一个系统
**输出**: 存量-流量-反馈结构图 + 行为预测
**完成标准**: 明确标注所有存量、流量、回路类型和延迟

## B — Boundaries
- 初学者易混淆存量和流量：问"这个量能在瞬间改变吗？"能→流量，不能→存量。

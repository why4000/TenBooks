# BOOK_OVERVIEW.md — 失控

## 元信息
- **书名**: 失控
- **作者**: 凯文·凯利 (Kevin Kelly)
- **类型**: 复杂系统/科技哲学
- **核心命题**: 复杂系统必须去中心化、自组织；造物九律是创造活系统的法则。

## 一、结构
全书24章，核心线索：
1. 人造与天生的融合（ch1-4）
2. 蜂群思维与涌现（ch2-3）
3. 共同进化（ch5-6）
4. 控制的兴起与失控（ch7-10）
5. 网络经济学与电子货币（ch11-12）
6. 人工进化（ch13-15）
7. 控制的未来与开放宇宙（ch16-18）
8. 后达尔文主义与造物九律（ch19-24）

## 二、核心术语骨架
- 涌现/蜂群思维/群体智能
- 共同进化/红皇后效应
- 控制论/反馈/必要多样性定律
- 人工进化/遗传算法
- 造物九律
- 网络效应

## 三、原书关键任务清单
1. 用涌现式思维理解复杂系统
2. 设计去中心化架构
3. 用进化算法搜索解空间
4. 应用造物九律设计活系统
5. 学会放手控制

# 厚度分析 (thickness-analysis)

## R — Rationale
媒介技术乐观主义常主张实现"透明""无摩擦"交流。但身体的厚度不可还原——完全透明会取消媒介本身。

## I — Intent
分析媒介技术的透明性主张，指出身体厚度的不可还原性，避免技术理想主义。

## A1 — 原书案例
作者指出：如果身体的"厚度"被超越，媒介变得完全透明，世界万事万物就毫无差别，媒介也就没有存在必要。这是技术理想主义忽视的根本问题。

## A2 — 适用边界
- 与 five-features-analysis 的区分：厚度是情境性/普遍性特征中的一个具体论点。
- 与 embodied-meta-medium 的区分：本能力聚焦不可还原性，后者确立根源地位。

## E — Execution
1. 识别技术主张中的"透明性"话语。
2. 追问：该技术预设了何种身体厚度？
3. 论证：完全消除该厚度为何不可能（会取消媒介本身）。
4. 指出：何种厚度是构成性的，不可被当作缺陷消除。

**输入**: 一个透明性技术主张
**输出**: 厚度不可还原性论证
**完成标准**: 明确指出何种厚度不可消除及理由

## B — Boundaries
- 不适用：不涉及意义/感知的纯物理传输。
- 注意：不要滑向保守主义——区分"构成性厚度"与"可改进的摩擦"。

# 五重特征分析 (five-features-analysis)

## R — Rationale
现象媒介不能用单一维度把握，它在五组二元对立中保持原初统一。需要一个框架同时处理这五重特征。

## I — Intent
从含混性/规范性、意向性/对象性、象征性/表达性、情境性/普遍性、主体性/主体间性五重特征分析具体媒介现象。

## A1 — 原书案例
作者对"身体厚度"的分析：在情境性/普遍性这一对中，身体的厚度既是具体情境中的限制，又是普遍视域的条件；完全透明会取消媒介本身。

## A2 — 适用边界与相邻能力区分
- 与 object-to-phenomenon-reduction 的区分：后者是还原方法，本能力是分析框架。
- 与 thickness-analysis 的区分：厚度是情境性/普遍性特征中的一个具体论点。

## E — Execution
1. 选定待分析的媒介现象。
2. 依次从五重特征提问：
   - 含混性：它是纯载体还是纯内容？如何是两者的原初统一？
   - 意向性：它体现了何种身体意向？
   - 象征性/表达性：它仅指涉现实，还是创造了新意义？
   - 情境性/普遍性：它在何种情境中生成？预设了何种普遍视域？
   - 主体性/主体间性：它如何建构现实？如何依赖主体间性？
3. 综合五重特征给出整体判断。

**输入**: 一个具体媒介现象
**输出**: 五重特征分析表 + 综合判断
**完成标准**: 五重特征均有分析，且显示出它们的内在关联

## B — Boundaries
- 不适用：非媒介现象（如纯自然过程）。
- 注意：五重特征不是独立维度，而是同一现象的不同侧面，分析时需保持关联。

# Book Glossary

- **对象媒介**: 被视为外在客观对象的媒介
- **现象媒介**: 显现在本己身体经验中的媒介
- **具身化**: 认知与传播根本上是身体性的
- **元媒介**: 身体作为最原初的媒介
- **现象身体**: 第一人称体验中的身体
- **补余逻辑**: 外延在延伸过程中形成，无先在内在性
- **技术意向性**: 技术继承并转化身体意向性
- **含混性**: 媒介既非纯载体也非纯内容
- **意向性**: 所有意识都是"关于某物的意识"
- **象征性**: 媒介在不同意义间建立指涉
- **表达性**: 媒介创造新意义
- **情境性**: 媒介总在具体情境中生成
- **普遍性**: 媒介预设普遍的世界视域
- **身体厚度**: 不可还原的身体不透明性
- **主体间性**: 身体间的相互朝向，奠基交流
- **现象学还原**: 悬置客观态度回到 lived experience

# Book Overview

## 主旨
本文通过现象学还原，批判主流传播学将媒介视为客观对象的预设，提出"现象媒介"概念，论证身体作为"元媒介"的存在论地位，并描述现象媒介的五重特征，为媒介学奠定新的存在论基础。

## 骨架
1. 破：对象媒介的预设及其困境（万物皆媒悖论、离身传播）
2. 立：身体作为元媒介，媒介的具身化
3. 展：现象媒介的五重特征
4. 收：现象媒介为媒介学奠基

## 关键论点
- 对象媒介是现象媒介的理论化产物
- 身体是"在世界上存在的媒介物"（元媒介）
- 媒介是身体的延伸，源于身体局限的克服
- 现象媒介五重特征：含混性、意向性、象征性、情境性、主体间性
- 身体的"厚度"不可还原，完全透明会取消媒介

# DIGEST — 理解媒介：从对象到现象

## 一句话精华
媒介不是客观对象，而是身体经验中生成的现象；对象媒介不过是现象媒介的理论化产物。

## 核心论证链

### 1. 破：对象媒介的困境
- 主流传播学把媒介等同于媒介物，视为外在客观对象
- 这导致两个问题：①"万物皆媒"取消了媒介学本身；②"离身传播"忽视了 lived experience
- 李普曼的"拟态/客观环境"二分本身就是对象化思维的产物

### 2. 立：身体作为元媒介
- 梅洛-庞蒂具身现象学：身体既非广延实体也非思维实体，而是原初综合
- "身体是在世界上存在的媒介物"——拥有身体就是介入一个环境
- 媒介源于身体局限的克服：距离→飞鸽/电报，移动→车/飞机，时空感知→报纸/电视
- 斯蒂格勒补余逻辑：延伸在延伸过程中形成，无先在内在性

### 3. 展：现象媒介五重特征
| 特征 | 核心 |
|---|---|
| 含混性/规范性 | 既非纯载体也非纯内容，是内容的形式与形式的内容 |
| 意向性/对象性 | 对象媒介是身体意向投入特定对象的结果 |
| 象征性/表达性 | 媒介即意义，即存有——不仅指涉，更创造 |
| 情境性/普遍性 | 情境中生成，预设普遍视域；身体厚度不可还原 |
| 主体性/主体间性 | 媒介建构现实；主体间性奠基交流 |

### 4. 收：存在论奠基
- 现象媒介为媒介学奠定新的存在论基础
- 引导重新审视媒介与人、自然、社会的关系

## 关键洞察
1. **现象先于对象**：我们对现象媒介熟视无睹，正如鱼无视水
2. **身体厚度不可消除**：完全透明=取消媒介；技术乐观主义忽视了这一点
3. **媒介即存有**：媒介不只是传递意义，更是意义/存在显现的方式

## 可迁移的方法论
- 对象→现象还原：任何被当作客观对象的概念，都可追溯其 lived experience 根源
- 厚度分析：任何"透明性"主张都可追问其预设的不可还原厚度
- 双重否定→双重肯定：处理"既非A也非B"的概念时，肯定其原初统一

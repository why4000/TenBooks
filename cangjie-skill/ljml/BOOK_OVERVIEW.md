# BOOK_OVERVIEW.md — 理解媒介：从对象到现象

## 元信息
- **书名**: 理解媒介：从对象到现象
- **作者**: 芮必峰、孙爽（安徽大学新闻传播学院）
- **类型**: 期刊论文（新闻大学 2021年第12期）
- **核心命题**: 媒介不是纯客观对象，而是与人类传播活动共生的现象；对象媒介源于现象媒介。

## 一、结构（Adler 四步）

### 1. 结构分析
全文四节，呈"破→立→展→收"结构：
1. **对象媒介与现象媒介** — 批判主流传播学的对象预设，提出现象媒介概念
2. **媒介的具身化** — 以梅洛-庞蒂具身现象学奠基，论证身体为元媒介
3. **现象媒介的主要特征** — 展开五重特征（含混/意向/象征/情境/主体间性）
4. **结语** — 现象媒介为媒介学奠定存在论基础

### 2. 解释
作者通过现象学还原，将被对象化的媒介追溯回身体经验中的现象媒介。核心论证链：
- 对象化导致"万物皆媒"悖论
- 身体是在世存在的媒介物（元媒介）
- 媒介是身体的延伸，源于身体局限的克服
- 五重特征是现象媒介的本质规定

### 3. 批判
- 优点：突破了传播学的离身困境，为媒介学提供了存在论根基
- 局限：纯理论推演，缺少经验研究支撑；对"如何操作化"未展开
- 内在张力：既批判客观主义，又试图建立"规范性"——规范性的来源是否仍需现象学自身奠基？

### 4. 应用
- 可用于反思智能媒介、具身传播研究
- 可用于批判媒介技术乐观主义（透明性理想）
- 可作为媒介哲学/理论研究的方法论框架

## 二、核心术语骨架
- 现象媒介 / 对象媒介
- 具身化 / 元媒介 / 现象身体
- 五重特征：含混性、意向性、象征性、情境性、主体间性
- 身体的厚度 / 补余逻辑 / 技术意向性

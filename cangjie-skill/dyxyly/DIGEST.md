# DIGEST — 第一性原理

## 一句话精华
任何系统都建在系统之外的基石假设上；创新不是改良，而是打破并重建基石假设。

## 核心论证链

### 1. 归纳法与演绎法
- 归纳法：实践→结论，依赖"连续性假设"，只能证伪不能证明
- 演绎法：前提→结论，依赖"前提准确"，逻辑比事实更真实
- 演绎法需要一个来自系统之外的前提→第一性原理

### 2. 第一性原理
- = 逻辑奇点 = 基石假设
- 必须在系统之外，不是系统内的结论
- 有层级之分：大系统的第一性原理可以是小系统的结论

### 3. 公理化思维
- 欧几里得《几何原本》：5条公理→465个命题
- 一切学问都是证明系统
- 公理是第一性原理的具体体现

### 4. 破界创新三部曲
1. 打破原有的基石假设
2. 定义新的、更广阔的基石假设
3. 在新基石上重建系统
- 难点：识别基石假设（太习以为常，"看不见"）

### 5. 第一创新（马斯克方法）
- 拆解问题到基本要素（不可再分）
- 从基本要素重新推导
- 例：火箭成本→原材料成本→自建→降一个数量级

### 6. 从众效应与批判性思维
- 人们相信的"真理"常是"所有人相信的"（真理连贯论）
- 逻辑三洽：自洽、他洽、续洽
- 不可知论："我讲的可能都是错的"

## 关键洞察
1. 基石假设决定系统边界，打破它才能外延边界
2. 拆解到基本要素是第一创新的操作方法
3. 从众效应是独立思考的最大敌人
4. 逻辑三洽是检验真理的可操作标准

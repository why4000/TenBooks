# Book Overview

## 主旨
任何理性系统都建立在系统之外的基石假设（第一性原理）之上。创新的本质是打破并重建基石假设，而非在既有方案上改良。

## 骨架
1. 原理层：归纳法vs演绎法→第一性原理
2. 方法层：公理化思维→破界创新三部曲
3. 应用层：组织刷新、第一创新（马斯克）、万物至理（爱因斯坦）
4. 反思层：从众效应→批判性思维（逻辑三洽）

## 关键论点
- 归纳法只能证伪，演绎法需要系统外前提
- 第一性原理=逻辑奇点=基石假设
- 破界创新：打破旧基石→定义新基石→重建系统
- 第一创新：拆解到基本要素重新推导
- 从众效应是独立思考的最大障碍
- 逻辑三洽（自洽/他洽/续洽）是检验真理的标准

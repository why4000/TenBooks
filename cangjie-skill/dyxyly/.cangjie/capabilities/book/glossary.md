# Book Glossary

- 第一性原理: 理性系统的根基性命题，来自系统之外
- 归纳法: 从实践推导结论，依赖连续性假设
- 演绎法: 从前提推导结论，依赖前提准确
- 连续性假设: 归纳法的隐含前提
- 公理化思维: 从公理出发演绎构建体系
- 破界创新: 打破基石假设重建系统
- 隐含假设: 未被审视的前提
- 第一创新: 从基本要素重新推导
- 多元思维模型: 跨学科基础模型的组合
- 从众效应: 个体倾向于与多数人一致
- 真理符合论: 真理=符合事实
- 真理连贯论: 真理=与群体信念一致
- 逻辑三洽: 自洽/他洽/续洽
- 不可知论: 承认认知有限
- 反共识: 真理常在少数人手中

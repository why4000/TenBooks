# 第一性原理推导 (first-principles-deduction)

## R — Rationale
多数创新是在既有方案上改良（归纳创新），受路径依赖限制。第一创新从基本要素重新推导，能突破既有框架。

## I — Intent
将问题拆解到不可再分的基本要素，从第一性原理出发重新推导解决方案。

## A1 — 原书案例
马斯克 SpaceX：火箭发射成本极高 → 拆解到原材料成本（铝、钛等）→ 发现原材料仅占成本2% → 自建火箭 → 成本降一个数量级。

## A2 — 适用边界
- 与 boundary-breaking-innovation 的区分：本能力是在既定系统内重新推导，后者是打破系统基石。
- 与 identify-implicit-assumptions 的区分：本能力是正向推导，后者是反向质疑。

## E — Execution
1. 界定问题。
2. 拆解到基本要素（不可再分）。
3. 对每个要素问：它的第一性原理是什么？（物理/化学/逻辑的基本事实）
4. 从基本要素重新组合，推导出新方案。
5. 用逻辑三洽检验。

**输入**: 一个问题
**输出**: 基于基本要素的新方案
**完成标准**: 方案的每个环节都可追溯到基本要素，无未经审视的中间假设

## B — Boundaries
- 不适用：纯艺术创作、无明确基本要素的领域。
- 注意：拆解深度要足够——拆到行业惯例以下。

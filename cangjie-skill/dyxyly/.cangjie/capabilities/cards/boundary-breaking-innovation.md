# 破界创新 (boundary-breaking-innovation)

## R — Rationale
当系统内改良达到极限，根本性突破只能来自打破系统的基石假设。破界创新是突破增长极限的方法。

## I — Intent
打破系统的隐含基石假设，建立更广阔的新基石，在新基石上重建系统。

## A1 — 原书案例
IBM：旧基石="计算机是大型企业的工具" → 新基石="计算机是个人工具" → PC革命。
乔布斯：旧基石="手机是通讯工具" → 新基石="手机是移动计算平台" → iPhone。

## A2 — 适用边界
- 与 first-principles-deduction 的区分：本能力是打破系统前提，后者是在前提内重新推导。
- 与 identify-implicit-assumptions 的区分：本能力包含识别+打破+重建三步。

## E — Execution
1. 列出系统所有"理所当然"的前提。
2. 逐一质疑，找到限制系统边界的那个基石假设。
3. 打破它（证明其不必然成立）。
4. 定义更广阔的新基石假设。
5. 从新基石出发，重建整个系统。

**输入**: 一个需要突破的系统
**输出**: 新基石假设 + 重建后的系统
**完成标准**: 新基石比旧基石更广阔，新系统边界外延

## B — Boundaries
- 不适用：系统运行良好，无需突破时。
- 风险：新基石可能错误——需用逻辑三洽和实践检验。

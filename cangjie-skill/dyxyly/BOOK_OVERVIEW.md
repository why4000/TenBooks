# BOOK_OVERVIEW.md — 第一性原理

## 元信息
- **书名**: 第一性原理
- **作者**: 李善友
- **类型**: 创新/哲学方法论
- **核心命题**: 任何理性系统都建立在系统之外的基石假设（第一性原理）之上；创新的本质是打破并重建基石假设。

## 一、结构
全书八章，呈"原理→方法→应用→反思"结构：
1. 第一性原理：归纳法vs演绎法，基石假设
2. 公理化思维：欧几里得方法
3. 破界创新：三部曲
4. 组织刷新：微软案例
5. 第一创新：马斯克、芒格
6. 万物至理：爱因斯坦
7. 从众效应：真理的真相
8. 批判性思维：逻辑三洽

## 二、核心术语骨架
- 第一性原理 / 基石假设 / 逻辑奇点
- 归纳法 / 演绎法 / 连续性假设
- 公理化思维 / 公理
- 破界创新三部曲
- 第一创新 / 多元思维模型
- 从众效应 / 真理符合论 / 真理连贯论
- 逻辑三洽 / 不可知论 / 反共识

## 三、原书关键任务清单
1. 区分归纳法与演绎法及其隐含假设
2. 确立第一性原理作为理性系统的根基
3. 掌握公理化思维方法
4. 执行破界创新三部曲
5. 应用第一创新（拆解到基本要素重新推导）
6. 识别并克服从众效应
7. 用逻辑三洽检验理论

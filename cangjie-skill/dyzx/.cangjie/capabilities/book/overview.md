# Book Overview

## 主旨
知识必须从不可怀疑处重建。笛卡尔先以普遍怀疑拆掉旧见解的地基，再以"我思"为阿基米德点，向上证明上帝存在、向下确立清楚分明标准，最后落到物体存在与身心实在区别。

## 骨架
1. 方法怀疑：拆基础而非拆个案
2. 我思故我在：不可再退的基点
3. 观念与客观实在性：因果充足原则
4. 真理与错误：意志越界，悬置判断
5. 本质与存在：本体论证明及其界限
6. 身心：实在区别又实在统一

## 关键论点
- 怀疑是通道，不是结论
- 我思是直观，不是三段论
- 清楚分明区分"看见"与"相信"
- 错误源于意志宽于理智，补救是停手
- 从定义到存在之间有一道坎
- 可分开设想不等于可分开存在
- 感觉报警利害，不解释本质

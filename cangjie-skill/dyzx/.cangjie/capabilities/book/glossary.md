# Book Glossary

- 方法怀疑: 凡有一点点可疑者一律悬置
- 悬置判断: 不下判断，而非下反向判断
- 成见: 自幼年接受、自动支配判断的旧见解
- 恶魔: 把怀疑推到极致的思想实验
- 我思故我在: 每次说出或想到时必真
- 思维之物: 本质即思维的东西（精神）
- 广延之物: 本质为广延、不能思维的东西（物体）
- 观念: 思维的一种样式，作为影像表象某物
- 客观实在性: 观念中表象的完满性程度
- 形式实在性: 原因中现实的完满性
- 卓越地存在: 以更高方式预先包含低级完满性
- 清楚分明: 当下呈现 + 边界锐利
- 自然的光明: 理性所照见的明见性
- 自然倾向: 仅使人倾向于相信的势力
- 无所谓: 未看清时的两可不偏，属最低自由
- 本质: 不因有无实例而失效的确定本性
- 实在区别: 可各自独立存在的区别
- 共同感官: 精神直接受感染的大脑最小部位

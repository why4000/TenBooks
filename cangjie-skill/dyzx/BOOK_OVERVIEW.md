# BOOK_OVERVIEW.md — 第一哲学沉思集

## 元信息
- **书名**: 第一哲学沉思集（Meditationes de prima philosophia）
- **作者**: 笛卡尔 (René Descartes)，庞景仁 译
- **版本**: 商务印书馆 汉译世界学术名著丛书
- **类型**: 形而上学 / 认识论
- **核心命题**: 要用普遍怀疑清除一切成见，找到"我思"这一不可怀疑的基点，再由此证明上帝存在与身心实在区别，并为"清楚分明者皆真"立下标准。

## 一、结构
全书由六篇连续的沉思构成，每篇一天，次序不可打乱；正文后附六组反驳与著者答辩，以及附录。

1. **第一个沉思**：论可以引起怀疑的事物——感官、梦境、恶魔三级怀疑，拆掉旧见解的基础。
2. **第二个沉思**：论人的精神的本性——"我思故我在"；蜡块论证；精神比物体更容易认识。
3. **第三个沉思**：论上帝及其存在——观念分类、客观实在性、因果充足原则。
4. **第四个沉思**：论真理和错误——清楚分明总则、意志越界、悬置判断。
5. **第五个沉思**：论物质性东西的本质——永恒本质；本体论证明。
6. **第六个沉思**：论物质性东西的存在——想象与领会之别、身心实在区别与统一。
7. **六组反驳与答辩**：卡特鲁斯、麦尔赛纳搜集的神学家、霍布斯、阿尔诺、伽森狄、第六组神学家与哲学家；另有附录三问与一封来信。

## 三、原书关键任务清单
1. 对既有信念做一次总体清算，找出它们共用的原则。
2. 在全面悬置后找到不可再退的基点（我思）。
3. 用清楚与分明两项检验观念的可靠性。
4. 沿客观实在性等级追查观念的来源。
5. 复盘错误：分清理智有限与意志越界。
6. 分清本质与存在，避免从定义直接跳到存在。
7. 判断身心是实在区别还是同一物的两面，并同时说明其统一。

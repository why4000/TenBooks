# DIGEST — 第一哲学沉思集

## 一句话精华
先拆掉一切可疑信念的地基，再从"我思"这个不可退的基点重建知识——清楚分明是唯一的标准，而错误来自意志跑在了理智前面。

## 六步链条
1. 拆地基 — 不逐条驳，只抽掉共用的原则
2. 找基点 — 怀疑无法取消"正在怀疑的我"
3. 向上推 — 无限者的观念必有无限的原因
4. 立标准 — 上帝非骗子，故清楚分明者皆真
5. 辨本质 — 本质永恒，但存在只在上帝处属于本质
6. 落存在 — 物体存在；身心实在区别又实在统一

## 核心洞察
1. 怀疑是手段：目的是"对后来发现是真的东西不再有怀疑"
2. 我思不是推论而是直观：每次重述时重新成立
3. 清楚≠强烈：自然的倾向常伪装成自然的光明
4. 错误不是无知，而是在无知处下了判断
5. 无所谓不是自由的高峰，而是认识不清的症状
6. 自由随明见增长，而非随选项增多
7. 可分开设想 ≠ 可分开存在
8. 感觉的职责是报警（利害），不是解释物体本质

## 关键判断
- 拆基础比驳个案有效
- 能在关键处停手，比想得更聪明更可靠
- 从定义到存在之间有一道坎，只有"存在属于本质"者可跨越
- 身心既区别又统一，只取一半就会失衡
- 错误不可能被消除，只能被识别与减少
